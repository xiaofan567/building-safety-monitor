任务6-1：机械设备总览

建议工时：

2

任务描述

机械设备总览用于对施工现场各类机械设备进行集中监控和管理。该页面采用左侧导航+右侧内容区的创新布局，提供总览、塔吊、升降机、深基坑、高支模等五种设备类型的切换展示，每种类型都包含平面图展示、数据统计和设备列表三个核心功能模块。

**知识点**：Vue3 组合式API、动态组件、组件通信、条件渲染、API数据交互、图标定位、状态管理

**重点**：动态组件切换、平面图标定位、设备列表渲染

**难点**：动态组件切换、设备图标定位、多类型设备数据的统一处理、组件间状态共享

**内容**：实现机械设备总览页面的完整功能，包括设备类型切换、平面图展示、设备图标定位、数据统计、设备列表展示等操作

**组件映射逻辑建议**：

```coffeescript
javascript
import TowerCraneOverview from '../components/TowerCraneOverview.vue'
import ElevatorOverview from '../components/ElevatorOverview.vue'
import DeepFoundationPitOverview from '../components/DeepFoundationPitOverview.vue'
import HighFormworkSupportOverview from '../components/HighFormworkSupportOverview.vue'
import allOverview from '../components/allOverview.vue'

const currentComponent = computed(() => {
  switch (type.value) {
    case 1: return TowerCraneOverview
    case 2: return ElevatorOverview
    case 3: return DeepFoundationPitOverview
    case 4: return HighFormworkSupportOverview
    case 5: return allOverview
    default: return allOverview
  }
})
```
