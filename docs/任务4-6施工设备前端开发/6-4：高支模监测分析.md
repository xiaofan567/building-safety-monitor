**7. 光源系统配置**

功能说明：

```csharp

  // 7.1 添加光源系统

// 光源系统配置函数
function addLights() {
  // 7.2 清除现有光源（避免重复添加）
  scene.children = scene.children.filter(child => 
    !(child instanceof THREE.Light)
  );
  
  // 7.3 环境光：提供基础均匀照明
  const ambientLight = new THREE.AmbientLight(0xffffff, 0.5);
  scene.add(ambientLight);
  
  // 7.4 主方向光1：从右上角照射，产生阴影和明暗对比
  const directionalLight1 = new THREE.DirectionalLight(0xffffff, 0.8);
  directionalLight1.position.set(10, 20, 10);
  scene.add(directionalLight1);
  
  // 7.5 辅助方向光2：从左下角照射，补充暗部细节
  const directionalLight2 = new THREE.DirectionalLight(0xffffff, 0.4);
  directionalLight2.position.set(-10, 10, -10);
  scene.add(directionalLight2);
}
```

关键参数解释：

THREE.AmbientLight(): 环境光，均匀照亮所有物体

颜色0xffffff：白色光

强度0.5：中等亮度

THREE.DirectionalLight(): 方向光，模拟太阳光，有方向性

主光强度0.8：较强的主光源

位置(10, 20, 10)：从右上前方照射

辅助光强度0.4：柔和的补充光源

位置(-10, 10, -10)：从左下后方照射

多光源设计：环境光 + 主方向光 + 辅助方向光，营造立体感

代码实现：

```csharp
  // 4.1 创建立柱网格
  let columnIndex = 0; // 立柱索引计数器
  
  // 4.2 双层循环创建网格布局
  for (let i = 0; i < columnCount; i++) {
    for (let j = 0; j < columnCount; j++) {
      
      // 4.3 计算立柱位置（网格分布）
      const x = (i - (columnCount - 1) / 2) * spacing;
      const z = (j - (columnCount - 1) / 2) * spacing;
      
      // 4.4 根据状态数据选择材质
      let material = normalMaterial; // 默认正常材质
      
      if (statusData.dangerColumns.includes(columnIndex)) {
        material = dangerMaterial; // 报警状态
      } else if (statusData.warningColumns.includes(columnIndex)) {
        material = warningMaterial; // 预警状态
      }
      
      // 4.5 创建圆柱体立柱
      const columnGeometry = new THREE.CylinderGeometry(
        columnRadius, // 顶部半径
        columnRadius, // 底部半径
        height,       // 高度
        16            // 分段数（圆滑度）
      );
      
      const column = new THREE.Mesh(columnGeometry, material);
      
      // 4.6 设置立柱位置
      // Y轴位置为高度一半，因为圆柱原点在中心
      column.position.set(x, height / 2, z);
      
      // 4.7 将立柱添加到模型组
      formworkGroup.add(column);
      
      columnIndex++; // 递增索引
    }
  }
```

关键参数解释：

位置计算：

(columnCount - 1) / 2: 计算中心偏移量

(i - 中心偏移) * spacing: 将索引转换为世界坐标

效果：立柱围绕原点(0,0,0)对称分布

状态判断逻辑：

statusData.dangerColumns: 报警立柱索引数组

statusData.warningColumns: 预警立柱索引数组

includes(columnIndex): 检查当前立柱是否在状态数组中

几何体参数：

CylinderGeometry: 创建圆柱体几何体

顶部/底部半径相同：创建直圆柱

高度height: 从配置获取

分段数16: 16边形近似圆形，平衡性能与效果

网格布局原理：

text

(0,0) (0,1) (0,2) (1,0) (1,1) (1,2) (2,0) (2,1) (2,2)

X方向：列索引i

Z方向：行索引j

Y方向：高度方向

```gml
// 5.1 辅助函数：创建横梁
function createBeam(x, y, z, length, thickness, material, isZAxis = false) {
  
  // 5.2 创建长方体几何体
  const beamGeometry = new THREE.BoxGeometry(
    isZAxis ? thickness : length, // X方向尺寸
    thickness,                     // Y方向尺寸（厚度）
    isZAxis ? length : thickness   // Z方向尺寸
  );
  
  // 5.3 创建网格对象
  const beam = new THREE.Mesh(beamGeometry, material);
  
  // 5.4 设置横梁位置
  beam.position.set(x, y, z);
  
  // 5.5 将横梁添加到模型组
  formworkGroup.add(beam);
  
  return beam;
}
```

关键参数解释：

参数说明：

x, y, z: 横梁中心位置坐标

length: 横梁长度

thickness: 横梁截面厚度

material: 横梁材质

isZAxis: 方向标志，false为X方向，true为Z方向

尺寸逻辑：

X方向横梁：长×厚×薄 (length × thickness × thickness)

Z方向横梁：薄×厚×长 (thickness × thickness × length)

通过isZAxis参数切换两个方向的尺寸

位置设置：

position.set(): 设置横梁在世界坐标系中的位置

通常放置在立柱的连接位置

```arduino
  // 7.1 创建横梁系统
  const beamLength = (columnCount - 1) * spacing; // 计算横梁长度
  
  // 7.2 X方向横梁（横向连接）
  for (let j = 0; j < columnCount; j++) {
    const z = (j - (columnCount - 1) / 2) * spacing;
    
    // 底部横梁（离地25%高度）
    createBeam(0, height * 0.25, z, beamLength, beamThickness, normalMaterial);
    
    // 中部横梁（50%高度）
    createBeam(0, height * 0.5, z, beamLength, beamThickness, normalMaterial);
    
    // 顶部横梁（100%高度）
    createBeam(0, height, z, beamLength, beamThickness, normalMaterial);
  }
  
  // 7.3 Z方向横梁（纵向连接）
  for (let i = 0; i < columnCount; i++) {
    const x = (i - (columnCount - 1) / 2) * spacing;
    
    // 底部横梁
    createBeam(x, height * 0.25, 0, beamLength, beamThickness, normalMaterial, true);
    
    // 中部横梁
    createBeam(x, height * 0.5, 0, beamLength, beamThickness, normalMaterial, true);
    
    // 顶部横梁
    createBeam(x, height, 0, beamLength, beamThickness, normalMaterial, true);
  }
  
  // 7.4 创建顶部模板
  const deckSize = beamLength + spacing * 0.5; // 模板稍大于横梁范围
  const deckGeometry = new THREE.PlaneGeometry(deckSize, deckSize, 10, 10);
  const deck = new THREE.Mesh(deckGeometry, deckMaterial);
  deck.rotation.x = -Math.PI / 2; // 旋转90度，水平放置
  deck.position.y = height + beamThickness / 2; // 放置在横梁上方
  formworkGroup.add(deck);
```

**横梁布局**：

三个高度层：25%、50%、100%高度

X方向与Z方向交错：形成网格状稳定结构

参数true：Z方向横梁

**顶部模板**：

PlaneGeometry: 平面几何体

细分10,10: 分成10×10网格，支持未来变形效果

rotation.x = -Math.PI/2: 绕X轴旋转-90度（水平放置）

透明度设计：半透明显示，不遮挡下方结构
