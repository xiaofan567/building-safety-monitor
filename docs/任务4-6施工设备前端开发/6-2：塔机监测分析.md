任务6-2：塔机监测分析

建议工时：

2

任务描述

塔机监测分析专门用于对塔式起重机进行实时监测和数据分析。该页面采用左中右三栏布局，提供完整的塔机运行状态监控、报警统计、实时数据展示和趋势分析功能。

**知识点**：Vue3 组合式API、ECharts图表、组件通信、条件渲染、API数据交互、定时器控制

**重点**：ECharts图表的使用、实时数据更新、多模块数据展示、设备切换功能

**难点**：ECharts图表的初始化和更新、实时数据定时获取、多模块数据同步、图表响应式适配

**内容**：实现塔机监测分析页面的完整功能，包括设备报警统计、报警趋势图表、设备信息、运行状态、实时工作数据、实时力矩和吊重趋势图表等。

##### 11. 实时数据更新

使用定时器每10秒更新一次实时数据，使用setInterval设置定时更新

```coffeescript
javascript
onMounted(() => {  
// ... 初始化图表和加载数据    
timer = setInterval(() => {   
 if (currentTowerId.value) {     
  loadTowerData(currentTowerId.value)   
   }  }, 10000) }) 
   onBeforeUnmount(() => {  clearInterval(timer)  // 销毁图表 })
```

##### 12. 图表销毁

在组件卸载前，清除定时器并销毁所有ECharts图表实例。
