任务描述

监测报警记录功能用于监控设备运行过程中的报警信息，提供报警查询、处理和统计分析。该页面采用响应式布局，包含多条件筛选、数据表格展示、报警处理交互和分页功能，帮助用户及时发现和处理设备异常。

**知识点**：Vue3组合式API、响应式数据管理、API数据交互、条件渲染、表格展示、分页组件、模态框交互

**重点**：API数据交互、条件渲染、表格展示、分页组件

**难点**：API数据交互、条件渲染、表格展示、分页组件、模态框交互

**内容**：实现设备报警记录页面的完整功能，包括报警筛选条件、数据表格展示、报警处理弹框、分页组件和状态管理。

##### 2. 筛选条件组件实现

![img](https://tecs-prod-static.obs.cn-north-1.myhuaweicloud.com/33d31ac81c734ed7acfbaafafebdeeda%2Frichtext%2Fimage%2F20251202%2F068fa731042a4af588118fb08be3029b.png)

筛选条件包含报警类型、时间范围、设备名称和处理状态：

```csharp
javascript
// 筛选条件数据结构
const filters = ref({
  alarmType: '',      // 报警类型：1-监测点报警，2-塔吊报警，3-升降机报警
  startDate: '',      // 开始日期
  endDate: '',        // 结束日期
  deviceName: '',     // 设备名称
  status: ''          // 处理状态：0-未处理，1-已处理
})

// 报警类型映射
const alarmTypeOptions = [
  { value: '', label: '请选择报警类型' },
  { value: '1', label: '监测点报警' },
  { value: '2', label: '塔吊报警' },
  { value: '3', label: '升降机报警' }
]

// 处理状态映射
const statusOptions = [
  { value: '', label: '请选择处理状态' },
  { value: '0', label: '未处理' },
  { value: '1', label: '已处理' }
]
```

**实现要点**：

使用select组件提供预定义选项

日期选择使用原生input[type="date"]

状态选择与表格状态标识保持一致

搜索按钮触发数据重新加载
