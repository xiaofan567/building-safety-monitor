### 1.背景及技术介绍

**1）背景**

在现代建筑施工中，塔吊作为关键的重型机械设备，其安全运行直接关系到工程进度和人员安全。传统的塔吊安全监测主要依赖于阈值报警和人工检查，这种方法存在明显的滞后性。当监测参数超过安全阈值时，危险往往已经发生或即将发生，缺乏足够的时间进行预防性干预。

**技术挑战**

- **数据复杂性**：塔吊运行数据包含多个相互关联的物理参数，如吊重、幅度、倾角、风速等，这些参数之间存在复杂的非线性关系
- **时序依赖性**：安全状态的变化是一个渐进过程，当前状态与历史运行数据密切相关
- **类别不平衡**：在实际运行中，危险状态相对较少，导致训练数据存在严重的类别不平衡问题
- **实时性要求**：预测模型需要在保证准确性的同时，满足工程现场的实时性要求

基于以上技术挑战，可使用深度学习神经网络技术，通过大量塔吊运行状态参数进行训练，实现可以根据塔吊运行参数序列来预测塔吊安全。

### 3.模型构建

由于塔吊危险预警的数据特点是**多维度时序数据、类别极度不平衡、危险模式具有时序依赖性**，需要解决**长期依赖捕捉、关键危险时刻识别、少数类样本学习**等问题，所以采用**LSTM+CNN+注意力机制**的混合神经网络架构。

**1）输入层与数据预处理**

```abnf
inputs = Input(shape=input_shape)
x = Masking(mask_value=-100.0)(inputs)
```

**首先添加输入层**：定义模型输入维度，适应塔吊传感器数据的时序特性

**然后添加掩码层**：处理传感器数据中可能存在的缺失值或无效数据，确保模型只关注有效时间步

**2）局部特征提取层**

```routeros
x = Conv1D(64, kernel_size=3, activation='relu', padding='same')(x)
x = BatchNormalization()(x)
x = Conv1D(128, kernel_size=5, activation='relu', padding='same')(x)
x = MaxPooling1D(pool_size=2)(x)
```

**接着添加1D卷积层**：使用不同大小的卷积核（3和5）捕捉塔吊数据的多尺度局部模式

小卷积核捕捉瞬时异常（如力矩突变）

大卷积核捕捉短期趋势（如风速持续上升）

**然后添加批归一化层**：加速训练收敛，提高模型稳定性

**最后添加池化层**：降低特征维度，保留重要特征的同时减少计算量

**3）时序依赖建模层**

```ini
lstm_out = Bidirectional(LSTM(192, return_sequences=True))(x)
```

**添加双向LSTM层**：捕捉塔吊危险状态的长期时序依赖关系

前向LSTM：分析当前状态与历史操作的关系

后向LSTM：结合后续状态变化验证危险模式

返回完整序列：为后续注意力机制提供每个时间步的隐藏状态

**4）关键特征关注层**

```ini
query = Dense(96)(lstm_out)
value = Dense(96)(lstm_out)
attention = Attention()([query, value])
x = Concatenate(axis=-1)([lstm_out, attention])
```

**构建注意力机制**：让模型自动学习关注塔吊数据中的危险关键时刻

查询和值变换：将LSTM输出映射到注意力空间

注意力计算：为每个时间步分配重要性权重

特征拼接：融合原始时序特征和注意力增强特征

**5）高级特征整合层**

```lisp
x = Bidirectional(LSTM(96, dropout=0.2, recurrent_dropout=0.2))(x)
x = BatchNormalization()(x)
x = Dense(128, activation='relu', kernel_regularizer='l2')(x)
x = Dropout(0.4)(x)
```

**添加第二层双向LSTM**：在注意力增强的基础上进一步整合时序信息

**添加全连接层与正则化**：

批归一化：稳定深层网络训练

L2正则化：防止过拟合，提高泛化能力

Dropout：随机失活，增强模型鲁棒性

**6）分类输出层**

```ini
outputs = Dense(num_classes, activation='softmax')(x)
```

**最后添加输出层**：生成三个类别的概率分布（安全/预警/危险）

7）**损失函数优化**

```apache
# 修改Focal Loss，大幅提升预警类权重
def weighted_focal_loss(y_true, y_pred):
    # 当前：危险0.4, 预警0.3, 安全0.3
    # 调整为：预警权重最高，危险次之，安全最低
    alpha = tf.where(tf.equal(y_true, 1), 0.6,    # 预警类权重最高
                    tf.where(tf.equal(y_true, 2), 0.3, 0.1))  # 危险0.3, 安全0.1
    
    gamma = 2.0
    ce_loss = tf.keras.losses.sparse_categorical_crossentropy(y_true, y_pred)
    pt = tf.exp(-ce_loss)
    return tf.reduce_mean(alpha * tf.pow(1 - pt, gamma) * ce_loss)
```

**采用加权Focal Loss**：专门针对塔吊数据中危险样本稀少的问题

提高危险类别的权重（0.4）

聚焦难分类样本，平衡类别分布

这种层次化设计使得模型能够：**底层捕捉局部异常**，**中层建模时序依赖**，**高层关注关键危险时刻**，最终实现准确的塔吊危险状态预警。最终代码如下：

```routeros
def build_attention_model(input_shape, num_classes):
    """构建带注意力机制的改进模型，增强对危险特征的关注"""
    # 输入层
    inputs = Input(shape=input_shape)
    
    # 特征提取层 - 增加卷积层以捕捉局部危险特征
    x = Masking(mask_value=-100.0)(inputs)
    x = Conv1D(64, kernel_size=3, activation='relu', padding='same')(x)
    x = BatchNormalization()(x)
    x = Conv1D(128, kernel_size=5, activation='relu', padding='same')(x)
    x = MaxPooling1D(pool_size=2)(x)
    
    # 双向LSTM层 - 增加单元数以捕捉更多时序特征
    lstm_out = Bidirectional(LSTM(192, return_sequences=True))(x)
    
    # 注意力机制 - 单独为危险特征设计注意力权重
    query = Dense(96)(lstm_out)
    value = Dense(96)(lstm_out)
    attention = Attention()([query, value])
    x = Concatenate(axis=-1)([lstm_out, attention])
    
    # 分类层
    x = Bidirectional(LSTM(96, dropout=0.2, recurrent_dropout=0.2))(x)
    x = BatchNormalization()(x)
    x = Dense(128, activation='relu', kernel_regularizer='l2')(x)
    x = Dropout(0.4)(x)  # 降低dropout率以保留更多特征
    outputs = Dense(num_classes, activation='softmax')(x)
    
    # 定义模型
    model = Model(inputs=inputs, outputs=outputs)
    
    # 修改Focal Loss，大幅提升预警类权重
	def weighted_focal_loss(y_true, y_pred):

    	# 调整为：预警权重最高，危险次之，安全最低
    	alpha = tf.where(tf.equal(y_true, 1), 0.6,    # 预警类权重最高
                    	tf.where(tf.equal(y_true, 2), 0.3, 0.1))  # 危险0.3, 安全0.1
    
	
    	gamma = 2.0
    	ce_loss = tf.keras.losses.sparse_categorical_crossentropy(y_true, y_pred)
    	pt = tf.exp(-ce_loss)
    	return tf.reduce_mean(alpha * tf.pow(1 - pt, gamma) * ce_loss)
    
    model.compile(
        optimizer=tf.keras.optimizers.Nadam(learning_rate=0.0005),
        loss=weighted_focal_loss,
        metrics=['accuracy']
    )
    return model
```

### 4.模型训练

在完成数据处理和模型构建后，继续进行模型训练配置，模型训练配置主要定义模型的训练轮次、训练批次、类别权重、设置早停机制、学习率调整和危险聚焦。

- 设置训练轮次为30轮、训练批次为256。类别权重对应值为1:4:8（安全：预警：危险）。
- 优化早停策略，设置早停参数为危险类别召回率，降低危险漏报的情况。
- 设置动态学习率，如五轮没有改善则将学习率减半。
- 设置危险聚焦，针对实时的危险召回率修改学习率。

```python
            noise_level = max(noise_level, 0.05)  # 增加危险样本的噪声
            noise = np.random.normal(0, noise_level, seq.shape)
            seq = np.clip(seq + noise, -3, 3)
        elif np.random.rand() < 0.5:  # 其他类别随机加噪
            noise = np.random.normal(0, noise_level, seq.shape)
            seq = np.clip(seq + noise, -3, 3)
            
        X.append(seq)
        y.append(current_label)
    
    return np.array(X), np.array(y).flatten()

def build_attention_model(input_shape, num_classes):
    """构建带注意力机制的改进模型，增强对危险特征的关注"""
    # 输入层
    inputs = Input(shape=input_shape)
    
    # 特征提取层 - 增加卷积层以捕捉局部危险特征
    x = Masking(mask_value=-100.0)(inputs)
    x = Conv1D(64, kernel_size=3, activation='relu', padding='same')(x)
    x = BatchNormalization()(x)
    x = Conv1D(128, kernel_size=5, activation='relu', padding='same')(x)
    x = MaxPooling1D(pool_size=2)(x)
    
    # 双向LSTM层 - 增加单元数以捕捉更多时序特征
    lstm_out = Bidirectional(LSTM(192, return_sequences=True))(x)
    
    # 注意力机制 - 单独为危险特征设计注意力权重
    query = Dense(96)(lstm_out)
    value = Dense(96)(lstm_out)
    attention = Attention()([query, value])
    x = Concatenate(axis=-1)([lstm_out, attention])
    
    # 分类层
    x = Bidirectional(LSTM(96, dropout=0.2, recurrent_dropout=0.2))(x)
    x = BatchNormalization()(x)
    x = Dense(128, activation='relu', kernel_regularizer='l2')(x)
    x = Dropout(0.4)(x)  # 降低dropout率以保留更多特征
    outputs = Dense(num_classes, activation='softmax')(x)
    
    # 定义模型
    model = Model(inputs=inputs, outputs=outputs)
    
    # 改进的Focal Loss，增加危险类的alpha权重
    def weighted_focal_loss(y_true, y_pred):
        # 调整后的权重：危险类0.5，预警类0.4，安全类0.1
        alpha = tf.where(tf.equal(y_true, 2), 0.5,  # 危险类权重
                        tf.where(tf.equal(y_true, 1), 0.4, 0.1))  # 预警类0.4，安全类0.1
        
        gamma = 2.0
        ce_loss = tf.keras.losses.sparse_categorical_crossentropy(y_true, y_pred)
        pt = tf.exp(-ce_loss)
        return tf.reduce_mean(alpha * tf.pow(1 - pt, gamma) * ce_loss)
    
    model.compile(
        optimizer=tf.keras.optimizers.Nadam(learning_rate=0.0005),
        loss=weighted_focal_loss,
        metrics=['accuracy']
    )
    return model

def get_fixed_weights():
    """固定类别权重，确保危险类获得足够关注但不过度惩罚"""
    # 标签编码：0=安全，1=预警，2=危险（根据实际编码调整）
    return {
        0: 1.0,    # 安全类
        1: 4.0,    # 预警类
        2: 8.0     # 危险类（降低权重至8倍，避免模型恐惧预测）
    }

def train_enhanced_model():
    """完整的训练流程，优化危险类识别"""
    # 数据准备（使用调整后字段的CSV文件）
    df = pd.read_csv('tower_crane_data.csv')
    le = LabelEncoder()
    df['安全状态编码'] = le.fit_transform(df['安全状态'])
    print("类别编码映射:", dict(zip(le.classes_, range(len(le.classes_)))))
    
    # 生成增强数据
    X, y = create_enhanced_sequences(df, seq_length=20, noise_level=0.03)
    print("输入数据形状:", X.shape, "标签形状:", y.shape)
    
    # 按时间顺序划分数据集
    split_idx = int(len(X)*0.8)
    X_train, X_val = X[:split_idx], X[split_idx:]
    y_train, y_val = y[:split_idx], y[split_idx:]
    
    # 使用固定权重替代动态权重
    class_weights = get_fixed_weights()
    print("\n类别权重分配:", class_weights)
    
    # 构建模型
    model = build_attention_model(
        input_shape=(20, X_train.shape[2]),
        num_classes=len(le.classes_)
    )
    model.summary()
    
    # 训练配置 - 增加轮次并调整早停策略
    history = model.fit(
        X_train, y_train,
        epochs=30,  # 增加训练轮次
        batch_size=256,  # 减小批次大小以增加参数更新频率
        validation_data=(X_val, y_val),
        class_weight=class_weights,
        callbacks=[
            EarlyStopping(patience=15, monitor='val_danger_recall', mode='max', 
                         restore_best_weights=True),  # 监控危险类召回率
            ReduceLROnPlateau(monitor='val_loss', factor=0.5, patience=5, verbose=1),
            DangerFocusCallback(val_data=(X_val, y_val), danger_class=2)
        ],
        verbose=2
    )
    
    # 最终评估
    y_pred = np.argmax(model.predict(X_val, verbose=0), axis=1)
    print("\n测试集详细评估:")
    print(classification_report(y_val, y_pred, target_names=le.classes_))
    
    # 模型保存
    model.save('enhanced_crane_model_v4.h5')
    np.save('label_classes.npy', le.classes_)

    print("\n模型已保存为 enhanced_crane_model_v4.h5")

if __name__ == "__main__":
    train_enhanced_model()
```
