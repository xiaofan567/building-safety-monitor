任务指导

### **1．升降机数据处理概述**

升降机设备通过物联网终端定时上报运行数据，主要包括实时状态数据与作业循环数据。系统需对上传数据进行识别、分类，并依据安全规则进行预警与报警判断，确保升降机运行安全。

**升降机数据的分类：**

**实时数据**：包括当前重量、运行速度、角度偏转、高度、门状态等；

**作业数据**：包括运行次数、循环时间、载荷记录等；

**报警规则说明：**

**超重报警**：超过额定重量90%预警，超过110%报警；

**超速报警**：超过额定速度90%预警，超过110%报警；

**角度偏转报警**：超过5度预警，超过8度报警；

**报警合并机制**：同一设备在短时间内多次触发报警时，应合并为一条报警记录，避免告警风暴。

**本任务的目标**：实现对升降机设备数据的分类存储与报警判断，并形成可查询的报警记录。

### **2．数据处理流程**

在之前的任务中已经实现了塔吊设备的数据存储与监测报警功能。在本任务中编写升降机处理类来处理升降机数据，包括升降机数据存储、升降机预警和报警监测。

升降机数据处理流程包括数据接收、类型判断、数据存储与报警判断四个阶段：

**数据接收**：设备通过TCP协议上报数据至平台；

**类型判断**：判断数据是否为升降机设备数据，并区分实时数据与作业数据；

**数据存储**：判断数据类型是实时数据还是作业数据，并分别存储；

**报警判断**：根据实时数据中的重量、速度与角度偏转，判断是否触发预警或报警，并生成报警记录；

### **5.升降机数据报警功能实现**

数据报警包括超重报警、超速报警和角度偏转报警。

1）超重报警

超重报警是检测标定重量和实际的重量差距，当实际重量超过标定重量的90%则需要发起预警。当超过标定重量110%则需要发起报警。在超重报警检测时，还需要实现报警合并功能。

```plaintext

            Object o = redisClient.get(RedisConst.ELEVATOR_ANGLE_HEAD + elevatorData.getAssetId());
            if(o!=null){
                Integer paId = (Integer) o;
                MonitorPointAlert pointAlert = monitorPointAlertMapper.selectById(paId);
                pointAlert.setRecoveryData(String.format("x轴角度：%s，y轴角度：%s",elevatorData.getXAngle(),elevatorData.getYAngle()));
                pointAlert.setRecoveryTime(new Date());
                monitorPointAlertMapper.updateById(pointAlert);
            }
            redisClient.delete(RedisConst.ELEVATOR_ANGLE_HEAD + elevatorData.getAssetId());
        }
    }
```
