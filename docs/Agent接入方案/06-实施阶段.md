# 06 · 实施阶段

> P0 ~ P6 七个阶段，每个阶段独立可发布、可回滚。P0-P1 是骨架与基础；P2-P4 是核心功能；P5 是稳定性；P6 是 RAG。

## 阶段总览

| 阶段 | 范围 | 周期 | 验证 | 是否阻塞后续 |
|------|------|------|------|-------------|
| **P0** | agent-service 骨架 + LangGraph 1.0 + Health | 1d | /agent/health 200 + 最小图跑通 | 阻塞所有 |
| **P1** | BFF + session + 前端切换（非流式） | 2d | 日报助手能对话 | 阻塞 P2 |
| **P2** | data_query 子图 + 真正 SSE + Timeline | 3d | "塔吊今日报警" → 工具可视化 | 阻塞 P3 |
| **P3** | ai_risk + tower_diag + HITL + 反思 | 4d | 写操作 HITL 流程跑通 | 阻塞 P4 |
| **P4** | report_gen + Time-Travel + 删 Coze | 3d | 日报生成 + 回放 | 阻塞 P5 |
| **P5** | DualTierCheckpointer + Trace 落库 + 监控 | 3d | 重启恢复 + 指标完整 | 阻塞 P6 |
| **P6** | RAG 全栈 + 评估 | 5d | RAGAS 阈值达标 | 不阻塞 P7 |
| **P7** | 定时日报 + 前端可配 cron/收件人/提示词 | 4d | 配 cron → 到点自动发送邮件 | - |

> 详见 [07-定时日报.md](./07-定时日报.md)
