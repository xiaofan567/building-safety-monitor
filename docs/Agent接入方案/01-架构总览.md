## 数据流

### 正常对话流

```
用户消息
   │
   ▼
[前端] AgentAssistant.vue (Composition API)
   │
   │ fetch SSE: POST /agent/chat
   ▼
[BFF] AgentController → AgentProxyService (WebClient)
   │
   │ HTTP + SSE: POST http://localhost:7000/agent/chat
   ▼
[Agent] FastAPI → LangGraph Pregel
   │
   ├─ input_guard
   ├─ load_session (从 Redis/MySQL 加载 checkpoint)
   ├─ KGCheck (cheap LLM 判断)
   ├─ Supervisor (LLM 决策)
   │   └─ 路由到子图
   ├─ 子图执行 (Agent ↔ Tools 循环)
   ├─ Reflector (LLM 评估)
   ├─ 输出护栏
   └─ save_trace_and_checkpoint (双写)
   │
   │ SSE 事件流 (token / tool_call / reflection / done)
   ▼
[BFF] 原样转发 SSE 到前端
   │
   ▼
[前端] 增量渲染 Markdown + Timeline 更新
```

### 写操作流（HITL）

```
ai_risk 子图决定调用 mark_ai_alert_handled (risk=medium)
   │
   ▼
hitl_check 节点
   │
   ├─ interrupt() 暂停执行
   ├─ 推 SSE 事件: human_confirm_required
   ▼
[BFF] 转发 interrupt 事件
   │
   ▼
[前端] 弹出 HumanConfirmDialog，显示具体动作
   │
   │ 用户点击"确认"
   │ fetch POST /agent/chat/resume
   ▼
[BFF] 转发 resume 到 agent
   │
   ▼
[Agent] 恢复执行 → tool_node → 调 Spring Boot API
```

### Time-Travel 流

```
用户进入 /agent/session/{id}/checkpoints
   │
   │ GET 列出所有 checkpoint
   ▼
返回 [{checkpoint_id, step, next_agent, tokens, summary}, ...]
   │
   │ 用户点击 checkpoint A → 选择"回放"或"分叉"
   │
   ├─ 回放：POST /agent/session/{id}/replay {checkpoint_id, message}
   │         → 加载 checkpoint 状态 → 注入新消息 → 继续执行 → SSE 流式返回
   │
   └─ 分叉：POST /agent/session/{id}/fork {checkpoint_id}
             → 创建新 thread_id → 复制状态 → 返回新 session_id
```

## 网络拓扑

```
浏览器
  ↓ HTTP (Admin-Token)
Spring Boot (:8080)
  ↓ HTTP / SSE
agent-service (:7000)
  ↓ HTTP + Admin-Token
Spring Boot (:8080)  [BFF 转发到后端业务 API]

同时：
  ↓ HTTP
AIRecognize (:5000)        [Flask，独立]
  ↓ TCP
device-sim-server (:3000)  [Node.js 模拟设备]

数据库：
  MySQL (:3306) - 业务数据 + LangGraph checkpoint + trace
  Redis (:6379) - 会话热数据 + 速率限制
  ChromaDB (in-process) - 向量库
```

## 与现有架构的关系

### 保留不变

- **AIRecognize (Python Flask)**：继续作为独立服务，提供 `/detect` 和 `/crane_safety` 接口
- **Spring Boot REST API**：所有 `/equipmentAssets/*`、`/monitorPointAlert/*` 等接口完全保留，Agent 作为新客户端
- **TCP 设备数据流**：Netty TCP Server → 业务处理器 → DB（不变）
- **AICameraService 后台检测循环**：5s/帧的摄像头 AI 检测流程不变

### 改造替换

- **Coze 智能助手**：`CozeConversationController` → `AgentController`（P4 阶段删除 Coze 代码）
- **DailyReportAssistant.vue** → **AgentAssistant.vue**

### 新增

- `agent-service/` 整个目录
- `docs/Agent接入方案/` 项目设计文档（本目录）
