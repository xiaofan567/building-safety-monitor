# 07 · 定时日报（P7）

> 在 [02-图设计.md](./02-图设计.md) 的 `report_gen` 子图基础上，扩展"定时自动发送日报"能力。
> 解决两个问题：(1) 谁来触发？(2) 怎么跳过人工 HITL？

## 2. HITL 方案：工具集分发

**选用方案 B**（详见讨论结论）：

| 方案 | 决策 |
|------|------|
| A. 同一工具 + 白名单跳过 HITL | ❌ 不选 |
| **B. 独立工具 `save_daily_report_auto` + 工具集分发** | ✅ **选用** |
| C. 草稿 + 人工复核 | ❌ 不选 |

**机制**：
- `save_daily_report` (risk=high)：人类用户的工具集，调它会触发 `interrupt()`
- `save_daily_report_auto` (risk=low)：**仅 system_user 工具集**包含；工具内部二次校验 `user_id in SYSTEM_USER_IDS`
- 工具集分发由 `app/tools/registry.py` 按身份组装

```python
# app/tools/registry.py
def get_tools_for(user_id: int) -> list:
    if user_id in settings.SYSTEM_USER_IDS:
        return NORMAL_TOOLS + SYSTEM_TOOLS    # 含 save_daily_report_auto
    return NORMAL_TOOLS                        # 只有 save_daily_report

SYSTEM_TOOLS = [save_daily_report_auto, ...]
NORMAL_TOOLS = [save_daily_report, ...]
```


## 4. 触发器（Spring Boot @Scheduled）

```java
// smartbuildings-backend/.../scheduledtasks/ScheduledReportTask.java
@Component
@RequiredArgsConstructor
@Slf4j
public class ScheduledReportTask {
    private final ReportScheduleService scheduleService;
    private final WebClient agentWebClient;

    /** 每分钟检查一次，由 cron 决定是否真的发送 */
    @Scheduled(cron = "0 * * * * ?")
    public void checkAndSend() {
        LocalDateTime now = LocalDateTime.now();
        List<ReportScheduleConfig> dueList =
            scheduleService.findDueSchedules(now);
        for (var cfg : dueList) {
            try {
                sendReport(cfg, now.toLocalDate());
            } catch (Exception e) {
                log.error("scheduled_report_failed", e);
                retryWithBackoff(cfg, e);
            }
        }
    }

    private void sendReport(ReportScheduleConfig cfg, LocalDate date) {
        // 1. 调 agent-service 生成日报
        var content = agentWebClient.post()
            .uri("/agent/report/scheduled")
            .bodyValue(new ScheduledReportRequest(
                cfg.getProjectId(), date.toString(),
                cfg.getPromptTemplate(), cfg.getMaxLength()
            ))
            .retrieve()
            .bodyToMono(String.class)
            .block(Duration.ofSeconds(120));

        // 2. 写 send_log (status=pending)
        var log = scheduleService.createSendLog(cfg, date, "scheduled", content);

        // 3. 发邮件 + webhook（任一失败不影响另一个）
        boolean emailOk = sendEmail(cfg.getEmails(), content);
        boolean webhookOk = sendWebhook(cfg.getWebhookUrls(), content);

        // 4. 更新 log 状态
        scheduleService.finishSendLog(log, emailOk, webhookOk);
    }

    private void retryWithBackoff(ReportScheduleConfig cfg, Exception lastError) {
        long[] backoffs = {1000, 2000, 4000};  // 1s/2s/4s
        for (int i = 0; i < backoffs.length; i++) {
            try {
                Thread.sleep(backoffs[i]);
                sendReport(cfg, LocalDate.now());
                return;
            } catch (Exception e) {
                log.warn("retry {} failed", i + 1, e);
            }
        }
        alertAdmin(cfg, lastError);  // 仍失败 → 告警
    }
}
```

## 5. agent-service 新增端点

```python
# app/api/report_scheduled.py
from fastapi import APIRouter
from pydantic import BaseModel
from app.graph.build import build_main_graph
from app.llm.client import get_llm

router = APIRouter()

class ScheduledReportRequest(BaseModel):
    project_id: int
    report_date: str       # "2026-10-09"
    prompt_template: str
    max_length: int = 3000

@router.post("/agent/report/scheduled")
async def scheduled_report(req: ScheduledReportRequest):
    """定时任务专用：跳过对话历史，直接调 report_gen"""
    # 用 system_user 身份
    state = {
        "user_id": settings.SYSTEM_USER_ID,
        "thread_id": f"scheduled-{req.project_id}-{req.report_date}",
        "session_id": f"scheduled-{req.project_id}-{req.report_date}",
        "messages": [HumanMessage(content=req.prompt_template.format(
            date=req.report_date, max_length=req.max_length
        ))],
        "input_guard": {"passed": True},
        "scratchpad": {},
    }
    config = {"configurable": {"thread_id": state["thread_id"]}}
    graph = build_main_graph()

    # 走 graph，路由到 report_gen
    result = await graph.ainvoke(state, config=config)

    # 提取最终答案
    final_msg = result["messages"][-1]
    content = final_msg.content if hasattr(final_msg, "content") else str(final_msg)

    # 强制转纯文本（去除 markdown 符号）
    content = strip_markdown(content)

    return {"content": content, "trace_id": result.get("trace_id")}
```

## 7. 失败处理

| 场景 | 处理 |
|------|------|
| 生成成功 / 邮件失败 / webhook 成功 | `status=partial`，记录两个渠道各自状态 |
| 生成成功 / 两个都失败 | `status=failed`，重试 3 次（1s/2s/4s），仍失败 → 告警 |
| 生成失败（agent 跑挂） | 立即告警，log status=failed |
| Spring Boot @Scheduled 没触发 | 监控告警：cron 1 分钟一次，>2 分钟无心跳则告警 |
| 部分重试 | 仅失败渠道重试，不重发成功的 |
