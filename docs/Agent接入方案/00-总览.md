# 00 · 总览

## 设计背景

`building-safety-monitor` 当前用 Coze 作为「智能监测助手」后端（`CozeConversationController` + 前端 `DailyReportAssistant.vue`）。

### 现有问题

1. **工具调用受限**：Coze Bot 的工具/插件能力有限，无法直接查询后端业务数据（设备、报警、监测点、AI 识别结果等）
2. **知识/插件非本地化**：所有逻辑在 Coze 平台，调试、审计、版本管理困难
3. **SSE 伪流式**：`CozeChatServiceImpl.callStreamApi` 解析 Coze 的 SSE 后合并为字符串一次性返回（`responseRaw`），前端体验差

### 改造目标

用 **LangGraph 1.0 多 Agent + Agentic RAG** 替代 Coze，目标是：

- **真正流式**：SSE token 增量推到前端
- **工具丰富**：每个子 Agent 都有专属工具集 + 共享的 RAG 工具
- **可观测**：Trace 全链路记录，Time-Travel 可回放
- **可控制**：Guardrails 防止越权、循环、超时；HITL 写操作确认
- **可审计**：Checkpoint 持久化到 MySQL，会话/历史长期可查
- **可恢复**：服务重启后历史会话自动恢复

## 关键决策

| 维度 | 决策 | 理由 |
|------|------|------|
| 场景 | 多 Agent 协同 | 4 业务场景（数据查询/AI 风险/塔吊诊断/日报）+ 1 知识场景 |
| 部署 | 独立 Python 微服务 | AI 已在 Python，LangGraph 生态最完整 |
| LangGraph | **1.0+** | 2025-12-12 GA，自带 durable execution |
| LLM | 中转站 OpenAI 兼容 API | 用户已确定走中转 |
| 路由 | Supervisor 全权路由 | LLM 决策，灵活 |
| RAG | **Agentic RAG** | 业界 2026 主流，自反思+引用校验 |
| 向量库 | ChromaDB → Qdrant | 开发零依赖，生产可替换 |
| Embedding | 中转站 embedding | 复用 LLM 通道 |
| 检索 | BM25 + Dense + Reranker | 混合检索，业界最佳实践 |
| Checkpoint | Redis 主存 + MySQL 持久化 | 热数据快读 + 冷数据审计 |
| 工具后端 | Spring Boot API 转发 | 复用业务逻辑、鉴权、校验 |
| 输出 | SSE 流式 + 中间过程事件 | 真正的流式 + 可观测 |
| Coze 关系 | 替代 | 用户明确选择 |
| 稳定性 | Trace + Time-Travel + Guardrails | 用户明确要求生产级 |
| 定时日报（P7） | Spring Boot @Scheduled + 前端可配 cron/收件人/提示词 | 报告自动化 + 运维自助 |
| Conflict Resolution HITL | 统一 `conflict_resolution_required` 中断 + 3 个 source（target_ambiguous / multi_source_conflict / low_confidence） | 目标模糊 + 多源说辞冲突 + RAG 置信度低时让人仲裁，与写操作 HITL 正交叠加 |

## LangGraph 1.0 关键变化

参考 [v1.0 Migration Guide](https://medium.com/@qasimwani618/langgraph-v1-0-migrating-from-0-x-to-1-0-c7a1faf6408d)：

| 项 | 0.x | 1.0 |
|----|-----|-----|
| Durable execution | 需显式 checkpointer | **默认开启**（`Pregel` 自动 checkpoint） |
| HITL `interrupt` | 实验性 | **GA**，与 `Command` 集成更顺 |
| Checkpointer | Postgres/SQLite/Redis | 同，**MySQL 仍需自实现** |
| LangSmith 集成 | 实验 | GA |
| Memory | 第三方 | 内置 long-term memory（`Store`） |

**依赖锁定**：

```toml
[tool.poetry.dependencies]
langgraph = "^1.0.0"                    # 锁定 1.0.x
langgraph-checkpoint-redis = "^1.0.0"
langchain-openai = "^0.3.0"
langchain-core = "^0.3.0"
langchain-text-splitters = "^0.3.0"
chromadb = "^0.5.0"
cohere = "^5.0.0"                       # rerank
```

## 范围与非范围

### 范围内

- ✅ 5 个子 Agent（Data Query / AI Risk / Tower Diag / Report Gen / Knowledge）
- ✅ Supervisor 路由 + Reflector 反思
- ✅ Guardrails（输入/输出/循环/工具/系统）
- ✅ Checkpoint 双层（Redis + MySQL）
- ✅ Trace 全链路
- ✅ Time-Travel API（fork/replay）
- ✅ Agentic RAG（hybrid + rerank + critic + composer + citation）
- ✅ HITL 写操作确认
- ✅ Conflict Resolution HITL（目标模糊 / 多源冲突 / 低置信度仲裁，详见 04 §4.7）
- ✅ SSE 流式 + 中间过程事件
- ✅ Spring Boot BFF（替代 Coze）
- ✅ 前端 AgentAssistant.vue（替代 DailyReportAssistant.vue）

### 范围外

- ❌ 多模态（图像直接喂给 LLM）：本阶段只文本；图像通过 AIRecognize 预处理后输出结构化结果
- ❌ Web 搜索：仅本地知识库 + 内部业务数据
- ❌ LangGraph Platform / LangSmith 商业化部署：自建可观测体系
- ❌ 移动端 / 微信小程序集成：仅 Web 端
- ❌ 多租户隔离：单租户
