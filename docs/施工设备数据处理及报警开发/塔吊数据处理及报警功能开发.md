### **1．塔吊数据处理概述**

塔吊设备通过物联网终端定时上报运行数据，主要包括实时状态数据与作业循环数据。系统需对上传数据进行识别、分类，并依据安全规则进行预警与报警判断，确保塔吊运行安全。

**塔吊数据的分类：**

**实时数据**：包括当前力矩、风速、幅度、高度、角度等；

**作业数据**：包括吊装次数、循环时间、载荷记录等；

**报警规则说明：**

**力矩报警**：超过额定力矩90%预警，超过110%报警；

**风速报警**：超过10.8m/s（6级风）预警，超过17.2m/s（8级风）报警；

**报警合并机制**：同一设备在短时间内多次触发报警时，应合并为一条报警记录，避免告警风暴。

**本任务的目标**：实现对塔吊设备数据的分类存储与报警判断，并形成可查询的报警记录。

### **2．数据处理流程**

在之前的任务中已经实现了TCP服务器搭建以及通用的设备数据存储与监测报警功能。但塔吊作为特殊的设备，还需专门编写处理类来处理塔吊数据，包括塔吊数据存储、塔吊预警和报警监测。

塔吊数据处理流程包括数据接收、类型判断、数据存储与报警判断四个阶段：

**数据接收**：设备通过TCP协议上报数据至平台；

**类型判断**：判断数据是否为塔吊设备数据，并区分实时数据与作业数据；

**数据存储**：判断数据类型是实时数据还是作业数据，并分别存储；

**报警判断**：根据实时数据中的力矩与风速，判断是否触发预警或报警，并生成报警记录；除此之外还需要实现通过AI塔吊风险预测服务实现风险预测。实现AI风险预测则需要先完成任务5-2-2。

### 5.塔吊数据报警功能实现

数据报警包括力矩报警、风速报警和AI预测报警。

1）力矩报警

力矩报警是检测标定力矩和实际的力矩的差距，当实际力矩超过标定力矩的90%则需要发起预警。当超过标定力矩110%则需要发起报警。在力矩报警检测时，还需要实现报警合并功能。报警合并功能可参考之前任务中的“设备监测报警功能开发”。

```wren
    /*
    * 判别力矩是否超出限制
    * @param towerInfo 塔机信息
    * @param towerData 实时数据
    * */
    void processMoment(TowerInfo towerInfo, TowerData towerData){
        Float moment = towerData.getMoment();
        Integer mpaId = (Integer) redisClient.get(RedisConst.TOWER_MOMENT_HEAD + towerInfo.getAssetId());
        //如果当前力矩大于额定力矩的90%，且之前没有报警记录，则添加报警信息
        if(moment != null && moment > towerInfo.getRatedMoment() * 0.9 &&mpaId == null){
            MonitorPointAlert pointAlert = new MonitorPointAlert()
                    .setEquipmentId(towerInfo.getAssetId())
                    .setCreateTime(new Date())
                    .setAlertType("0")
                    .setContent("力矩预警")
                    .setMonitorLog(String.format("力矩预警，当前力矩：%s，额定力矩：%s \r\n", moment, towerInfo.getRatedMoment()))
                    .setMonitorData(moment.toString());
            if(moment > towerInfo.getRatedMoment() * 1.1){
                pointAlert.setAlertType("1");
                pointAlert.setMonitorAlertType("2");
                pointAlert.setContent("力矩报警");
                pointAlert.setMonitorLog(String.format("力矩报警，当前力矩：%s，额定力矩：%s \r\n", moment, towerInfo.getRatedMoment()));
            }
            monitorPointAlertMapper.insert(pointAlert);
            redisClient.set(RedisConst.TOWER_MOMENT_HEAD + towerInfo.getAssetId(), pointAlert.getId(),15, TimeUnit.MINUTES);

        }
        else if(moment != null && moment > towerInfo.getRatedMoment() * 0.9){
            //如果之前有报警记录，且当前力矩大于额定力矩的90%，则更新报警信息
            MonitorPointAlert pointAlert = monitorPointAlertMapper.selectById(mpaId);
            if(pointAlert != null){
                String addLog = String.format("力矩预警，当前力矩：%s，额定力矩：%s \r\n", moment, towerInfo.getRatedMoment());
                if(moment > towerInfo.getRatedMoment() * 1.1){
                    pointAlert.setAlertType("1");
                    pointAlert.setContent("力矩报警");
                    addLog = String.format("力矩报警，当前力矩：%s，额定力矩：%s \r\n", moment, towerInfo.getRatedMoment());
                }
                pointAlert.setMonitorLog(pointAlert.getMonitorLog() + addLog);
                monitorPointAlertMapper.updateById(pointAlert);
            }
        }
        else if (moment != null && moment <= towerInfo.getRatedMoment() * 0.9 && mpaId != null){
            //如果之前有报警记录，且当前力矩小于额定力矩的90%，则更新报警信息，结束报警
            MonitorPointAlert pointAlert = monitorPointAlertMapper.selectById(mpaId);
            if(pointAlert != null){
                pointAlert.setRecoveryData(moment.toString());
                pointAlert.setRecoveryData(moment.toString());
                monitorPointAlertMapper.updateById(pointAlert);
                redisClient.delete(RedisConst.TOWER_MOMENT_HEAD + towerInfo.getAssetId());
            }
        }
    }
```

1.在tcpserver/handle中创建DeviceDataProcessHandle抽象类，用于实现设备处理功能。

```plaintext
public abstract class DeviceDataProcessHandle<T> {
    protected Map<String, T> dataMap = new HashMap<>();
    public abstract void init();
    /*
    * 塔机设备数据处理
    * 首先根据设备对接码获取塔机信息，如果没有则不处理
    * 然后判断是工作记录还是实时数据，然后保存
    * 如果是实时数据，则还需要进行报警判断
    * 风速报警 6级风预警 8级风报警
    * 力矩报警 90%额定力矩预警 110%额定力矩报警
    * @param data 设备数据
    * */
    @Async("DataProcessTaskExecutor")
    public abstract void processData(DeviceReportDTO data);
    //更新数据方法
    public void update(T data, String key, UpdateOperationEnum operationEnum){
        if (operationEnum == UpdateOperationEnum.DELETE){
            dataMap.remove(key);
        }else {
            dataMap.put(key,data);
        }
    }
}
```

```plaintext
@Component
public class TCPNettyServer {
    private static final Logger log = LoggerFactory.getLogger(TCPNettyServer.class);

    private int TCP_PORT=8888;
    // 配置参数
    private EventLoopGroup bossGroup;
    private EventLoopGroup workerGroup;
    // 移除内部的 clientChannels，改为使用 TCPClientPool
    @Autowired
    private TCPClientPool tcpClientPool;
    private Thread nettyServerThread;
    // 注入依赖
    @Autowired
    private ObjectMapper objectMapper;
    @Autowired
    private EquipmentAssetsDataProcessHandle equipmentAssetsDataProcessHandle;
    @Autowired
    private TowerDataProcessHandle towerDataProcessHandle;
    private List<DeviceDataProcessHandle> handleList=new ArrayList<>();

    // 定义最大帧长度为1MB
    private static final int MAX_FRAME_LENGTH = 1024 * 1024;
    private static final int LENGTH_FIELD_OFFSET = 0;
    private static final int LENGTH_FIELD_LENGTH = 4;
    private static final int LENGTH_ADJUSTMENT = 0;
    private static final int INITIAL_BYTES_TO_STRIP = 4;
    /**
     * 服务器启动方法，使用@PostConstruct注解确保在当前Bean初始化完成后自动执行
     */
    @PostConstruct
    public void startServer() {
        handleList.add(towerDataProcessHandle);
        // 创建独立线程用于启动Netty服务器，避免阻塞Spring容器初始化（因Netty启动含阻塞操作）
        nettyServerThread = new Thread(() -> {
            try {
                // 初始化boss线程组：负责接收客户端连接，此处指定1个线程（通常无需多个）
                bossGroup = new NioEventLoopGroup(1);
                // 初始化worker线程组：负责处理已连接客户端的IO操作，默认线程数为CPU核心数×2
                workerGroup = new NioEventLoopGroup();

                // 构建Netty服务端启动器
                ServerBootstrap bootstrap = new ServerBootstrap()
                        // 绑定boss和worker线程组
                        .group(bossGroup, workerGroup)
                        // 指定服务端通道类型为NIO（非阻塞IO，适合高并发场景）
                        .channel(NioServerSocketChannel.class)
                        // 设置TCP参数：SO_BACKLOG表示未完成三次握手的连接队列大小
                        .option(ChannelOption.SO_BACKLOG, 100)
                        // 设置客户端连接参数：SO_KEEPALIVE启用TCP心跳机制，检测死连接
                        .childOption(ChannelOption.SO_KEEPALIVE, true)
                        // 配置新连接的处理器初始化器（每个客户端连接建立时都会执行initChannel）
                        .childHandler(new ChannelInitializer<SocketChannel>() {
                            @Override
                            protected void initChannel(SocketChannel ch) throws Exception {
                                // 获取当前通道的处理器流水线（责任链模式，按添加顺序执行）
                                ChannelPipeline pipeline = ch.pipeline();

                                // 添加长度字段解码器：解决TCP粘包/拆包问题
                                // 帧格式约定为 [4字节长度][JSON数据]，参数对应协议格式配置
                                pipeline.addLast(new LengthFieldBasedFrameDecoder(
                                        MAX_FRAME_LENGTH,       // 最大帧长度（防止超大报文攻击）
                                        LENGTH_FIELD_OFFSET,   // 长度字段在帧中的起始偏移量
                                        LENGTH_FIELD_LENGTH,   // 长度字段占用的字节数（此处为4字节int）
                                        LENGTH_ADJUSTMENT,     // 长度调整值（通常为0，若长度包含自身则需修正）
                                        INITIAL_BYTES_TO_STRIP // 解码后跳过的字节数（跳过长度字段，只保留数据）
                                ));

                                // 添加字符串解码器：将字节流转换为UTF-8编码的字符串
                                pipeline.addLast(new StringDecoder(CharsetUtil.UTF_8));
                                // 添加字符串编码器：将字符串转换为UTF-8编码的字节流
                                pipeline.addLast(new StringEncoder(CharsetUtil.UTF_8));

                                // 添加自定义业务处理器，传入依赖的连接池、JSON工具和业务服务
                                pipeline.addLast(new TcpServerHandler(
                                        tcpClientPool, // 客户端连接池（管理所有TCP连接）
                                        objectMapper, // JSON序列化工具
                                        equipmentAssetsDataProcessHandle // 业务处理服务
                                ));
                            }
                        });

                // 绑定监听端口并同步等待绑定完成（阻塞操作，直到端口绑定成功）
                ChannelFuture future = bootstrap.bind(TCP_PORT).sync();
                log.info("TCP Netty Server 启动成功，监听端口：{}", TCP_PORT);
                // 阻塞等待服务器通道关闭（即保持服务器运行，直到主动关闭）
                future.channel().closeFuture().sync();

            } catch (InterruptedException e) {
                log.error("TCP Netty Server 启动异常或被中断", e);
                // 恢复线程中断状态，便于上层逻辑感知中断事件
                Thread.currentThread().interrupt();
            } finally {
                // 优雅关闭线程组，释放资源（无论启动成功与否均执行）
                if (bossGroup != null) bossGroup.shutdownGracefully();
                if (workerGroup != null) workerGroup.shutdownGracefully();
                // 服务器关闭时清理所有客户端连接，避免资源泄漏
                tcpClientPool.removeAll();
            }
        }, "Netty-TCP-Server-Thread"); // 线程命名，便于日志和监控识别

        // 启动Netty服务器线程
        nettyServerThread.start();
    }

     * 停止Netty服务器

    @PreDestroy

        if (workerGroup != null) workerGroup.shutdownGracefully();

    /**
     * 自定义ChannelHandler：处理Netty的IO事件，使用TCPClientPool管理连接
     */
    public class TcpServerHandler extends SimpleChannelInboundHandler<String> {
        private final TCPClientPool tcpClientPool;
        private final ObjectMapper objectMapper;
        private final EquipmentAssetsDataProcessHandle equipmentAssetsDataProcessHandle;
        // 构造函数注入所有依赖
        public TcpServerHandler(TCPClientPool tcpClientPool,
                                ObjectMapper objectMapper, EquipmentAssetsDataProcessHandle equipmentAssetsDataProcessHandle) {
            this.tcpClientPool = tcpClientPool;
            this.objectMapper = objectMapper;
            this.equipmentAssetsDataProcessHandle = equipmentAssetsDataProcessHandle;
        }
        @Override
        public void channelActive(ChannelHandlerContext ctx) throws Exception {
            Channel channel = ctx.channel();
            String clientId = getClientId(channel);
            // 使用TCPClientPool注册客户端
            tcpClientPool.register(clientId, channel);
            log.info("新客户端连接：{}，当前连接数：{}", clientId, tcpClientPool.getConnectionCount());
            equipmentAssetsDataProcessHandle.deviceConnect(clientId);
        }
        @Override
        protected void channelRead0(ChannelHandlerContext ctx, String receivedData) throws Exception {
            Channel channel = ctx.channel();
            String clientId = getClientId(channel);

            try {
                // 使用Jackson的流式API处理JSON数据
                JsonParser parser = objectMapper.getFactory().createParser(receivedData);
                DeviceReportDTO reportDTO = objectMapper.readValue(parser, DeviceReportDTO.class);
                // 数据校验
                validateReportData(reportDTO, clientId);
                // 处理设备数据
                equipmentAssetsDataProcessHandle.processEquipmentAssetsData(reportDTO, clientId);
                for (DeviceDataProcessHandle handle : handleList) {
                    handle.processData(reportDTO);
                }
                // 构建响应
                String response = String.format("{\"status\":\"success\", \"message\":\"数据已接收\", \"timestamp\":%d}",
                        System.currentTimeMillis());
                sendResponse(channel, response);
            } catch (JsonProcessingException e) {
                log.error("客户端[{}]数据解析失败：{}", clientId, receivedData, e);
                sendResponse(channel, "{\"status\":\"error\", \"message\":\"数据格式错误\"}");
            } catch (IllegalArgumentException e) {
                log.error("客户端[{}]数据验证失败：{}", clientId, e.getMessage());
                sendResponse(channel, String.format("{\"status\":\"error\", \"message\":\"%s\"}", e.getMessage()));
            } catch (Exception e) {
                log.error("客户端[{}]数据处理异常", clientId, e);
                sendResponse(channel, "{\"status\":\"error\", \"message\":\"服务器处理失败\"}");
            }
        }
        @Override
        public void channelInactive(ChannelHandlerContext ctx) throws Exception {
            Channel channel = ctx.channel();
            String clientId = getClientId(channel);
            // 使用TCPClientPool移除客户端
            tcpClientPool.remove(clientId);
            log.info("客户端[{}]连接断开，当前连接数：{}", clientId, tcpClientPool.getConnectionCount());
            equipmentAssetsDataProcessHandle.deviceOffline(clientId);
        }
        @Override
        public void exceptionCaught(ChannelHandlerContext ctx, Throwable cause) throws Exception {
            Channel channel = ctx.channel();
            String clientId = getClientId(channel);
            log.error("客户端[{}]连接异常", clientId, cause);
            // 移除异常客户端
            tcpClientPool.remove(clientId);
            equipmentAssetsDataProcessHandle.deviceOffline(clientId);
            ctx.close();
        }
        /**
         * 发送响应给客户端，添加长度前缀
         */
        private void sendResponse(Channel channel, String response) {
            try {
                byte[] responseBytes = response.getBytes(CharsetUtil.UTF_8);
                ByteBuf buffer = Unpooled.buffer(4 + responseBytes.length);
                buffer.writeInt(responseBytes.length);
                buffer.writeBytes(responseBytes);
                channel.writeAndFlush(buffer);
            } catch (Exception e) {
                log.error("发送响应失败", e);
            }
        }

        /**
         * 验证上报数据的合法性
         */
        private void validateReportData(DeviceReportDTO reportDTO, String clientId) {
            if (reportDTO.getId() == null || reportDTO.getId().trim().isEmpty()) {
                throw new IllegalArgumentException("设备ID不能为空");
            }
            if (reportDTO.getProperties() == null || reportDTO.getProperties().isEmpty()) {
                throw new IllegalArgumentException("设备属性不能为空");
            }
        }

        private String getClientId(Channel channel) {
            return channel.remoteAddress().toString().replace("/", "");
        }
    }
```
