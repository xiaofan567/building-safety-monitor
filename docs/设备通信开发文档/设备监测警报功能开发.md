任务指导

### 1．设备监测报警概述

在智慧工地系统中，设备通过物联网平台持续上报运行数据（如温度、压力、振动频率等）。设备监测报警功能旨在对接收到的设备数据进行实时分析，识别异常状态，并及时发出预警或报警信息，帮助管理人员快速响应，避免设备故障或安全事故。

**设备监测报警的核心流程包括：**

**数据接收与解析**：系统接收设备上报的数据报文，解析出设备编号、监测点属性及对应数值；

**监测点匹配**：根据设备编号找到其关联的监测点配置，识别需要监控的属性和阈值；

**阈值判断**：将解析出的数据与监测点中设定的预警值、报警值进行比较，判断是否触发预警或报警；

**报警合并处理**：为防止短时间内重复报警，系统对同一监测点的连续异常数据进行合并处理，形成一条持续的报警记录；

**状态恢复判断**：当监测数据恢复正常时，系统自动结束报警记录，并记录恢复数值与时间；

**报警记录管理**：提供报警记录的查询、处理与归档功能。

### 4．设备监测报警功能设计

### 4.1 设备报警值设置机制

设备报警值的设置基于监测点的配置，支持多种数值计算方式，确保报警判断的准确性和灵活性。

**报警值计算类型：**

 

| 计算类型   | 描述                                 | 适用场景                                 |
| ---------- | ------------------------------------ | ---------------------------------------- |
| **实时值** | 直接使用当前采集的监测数值           | 瞬时状态监控，如设备开关状态、即时温度等 |
| **最大值** | 在指定时间窗口内取监测数值的最大值   | 峰值监控，如压力峰值、温度最高值等       |
| **最小值** | 在指定时间窗口内取监测数值的最小值   | 谷值监控，如最低电压、最小流量等         |
| **平均值** | 在指定时间窗口内计算监测数值的平均值 | 趋势监控，如平均能耗、平均温度等         |
| **总和**   | 在指定时间窗口内累计监测数值的总和   | 累计量监控，如总产量、总能耗等           |

**报警值处理流程：**

**1.实时数据获取**：系统接收设备上报的实时监测数据

**2.时间窗口配置**：根据监测点配置的时间窗口参数（如：5分钟、15分钟、1小时）

**3.有效值计算**：

如果时间窗口设置为0，直接使用实时值作为有效值

否则，在指定时间窗口内按照配置的计算类型（最大值/最小值/平均值/总和）计算有效值

**4.阈值比较**：将计算得到的有效值与监测点配置的预警阈值和报警阈值进行比较

在进行数值计算时，因为各个监测点设置的时间窗口不同、并且的设备上报数据的时间间隔也无法控制，所以可以使用Redis缓存加前缀查询的方法进行数据统计。

在获取数据后，将数据存放在Redis缓存中，其缓存键格式为"[固定前缀][监测点ID]__[随机值]"格式存储，并设置缓存的过期时间为检测时间窗口。在查询时则查询"[固定前缀][监测点ID]__"为前缀的所有键，超出时间窗口的键会自动失效，然后将所有可查到的键进行数据处理。需要注意的是Redis存储键值对需要一定时间，所以需要先查出来之前的数据，然后加入新数据作为数据计算，最后再将新数据存入Redis。

参考代码：

```pgsql
    /*
    * 根据设备信息与监测点设置进行数据检测
    * */
    private void processPoint(DeviceReportDTO data, EquipmentMonitorPoint point) {
        //根据DTO中的数据与监测点数据是否匹配，判断是否需要进行数据处理
        String s = data.getProperties().get(point.getDeviceCode());
        if(s!=null){
            MonitorValue pointValue = new MonitorValue();
            pointValue.setEquipmentId(point.getEquipmentId());
            pointValue.setMonitorPointId(point.getId());
            pointValue.setMonitorData(s);
            pointValue.setMonitorTime(new Date());
            monitorPointValueMapper.insert(pointValue);
            // 数值预警处理，先判断是否为数字
            if (!s.matches("-?\\d+(\\.\\d+)?")) {
                return;
            }
            Double dataValue = Double.valueOf(s);
            //如果是喷淋设备，需要根据状态进行处理
            spraySystemDataProcessService.processSpraySystemData(point,dataValue);

            //如果匹配，则先判断检测时间为0的情况
            if (point.getRangeTime()==null||point.getRangeTime()==0){
                //如果检测时间为0，则直接进行数据处理
                checkPoint(point,dataValue);
            }else{
                // 如果时间不为0，则需要先计算，再存入Redis，如果先存再计算，可能出现存上去，get不返回数据的情况
                Set<String> set = redisClient.getKeysByPrefix(String.format("%s%d_", PROPERTY_NAME_HEAD, point.getId()));
                switch (point.getStatisticalType()) {
                    case "1":
                        // 平均值计算（使用迭代器遍历）
                        Iterator<String> avgIterator = set.iterator();
                        while (avgIterator.hasNext()) {
                            String key = avgIterator.next();
                            Object o = redisClient.get(key);
                            if (o == null) {
                                avgIterator.remove(); // 迭代器安全删除，避免并发修改异常
                                continue;
                            }
                            // 增加类型判断，避免ClassCastException
                            if (o instanceof Double) {
                                dataValue += (Double) o;
                            }
                        }
                        dataValue /= (set.size() + 1); // 包含当前数据的平均值
                        break;

                    case "2":
                        // 最大值计算（使用迭代器遍历）
                        Iterator<String> maxIterator = set.iterator();
                        while (maxIterator.hasNext()) {
                            String key = maxIterator.next();
                            Object o = redisClient.get(key);
                            if (o == null) {
                                maxIterator.remove(); // 迭代器安全删除
                                continue;
                            }
                            if (o instanceof Double) {
                                dataValue = Math.max(dataValue, (Double) o);
                            }
                        }
                        break;

                    case "3":
                        // 最小值计算（使用迭代器遍历）
                        Iterator<String> minIterator = set.iterator();
                        while (minIterator.hasNext()) {
                            String key = minIterator.next();
                            Object o = redisClient.get(key);
                            if (o == null) {
                                minIterator.remove(); // 迭代器安全删除
                                continue;
                            }
                            if (o instanceof Double) {
                                dataValue = Math.min(dataValue, (Double) o);
                            }
                        }
                        break;

                    case "4":
                        // 总和计算（使用迭代器遍历）
                        Iterator<String> sumIterator = set.iterator();
                        while (sumIterator.hasNext()) {
                            String key = sumIterator.next();
                            Object o = redisClient.get(key);
                            if (o == null) {
                                sumIterator.remove(); // 迭代器安全删除
                                continue;
                            }
                            if (o instanceof Double) {
                                dataValue += (Double) o;
                            }
                        }
                        break;
                }
                redisClient.set(String.format("%s%d_%s",PROPERTY_NAME_HEAD,point.getId(), UUID.randomUUID()),
                        dataValue,
                        point.getRangeTime(),
                        TimeUnit.SECONDS);
                log.info("监测点id为{}的监测数据为{}",point.getId(),dataValue);
                checkPoint(point,dataValue);

            }
        }
        return;
    }
```

 

### 4.2 报警判别机制

基于有效值的报警判别采用分级阈值判断策略：

**报警级别判定：**

 

| 有效值条件                                                   | 报警级别     | 处理动作                   |
| ------------------------------------------------------------ | ------------ | -------------------------- |
| 有效值 ≥ 报警上限 **或** 有效值 ≤ 报警下限                   | **报警级别** | 触发紧急报警，需要立即处理 |
| 预警上限 ≤ 有效值 < 报警上限 **或** 预警下限 ≥ 有效值 > 报警下限 | **预警级别** | 触发预警通知，需要关注     |
| 预警下限 < 有效值 < 预警上限                                 | **正常状态** | 无报警，记录监测数据       |

**判别流程：**

首先判断是否达到报警阈值

如未达到报警阈值，再判断是否达到预警阈值

记录判别结果和触发数值

参考代码：

```pgsql
    /*
    * 监测数据是否超出预警值或者报警值的范围
    */
    private void checkPoint(EquipmentMonitorPoint point, Double value){
        if (point.getAlarmUpper()!=null&&value>point.getAlarmUpper()){
            //如果超出报警值范围，则发送报警消息
            sendAlarmMessage(point,value,1);
        }
        else if (point.getAlarmLower()!=null&&value.compareTo(point.getAlarmLower())<0){
            //如果超出报警值范围，则发送报警消息
            sendAlarmMessage(point,value,2);
        }
        else if (point.getWarnUpper()!=null&&value.compareTo(point.getWarnUpper())>0){
            //如果超出预警值范围，则发送预警消息
            sendAlarmMessage(point,value,3);
        }
        else if (point.getWarnLower()!=null&&value.compareTo(point.getWarnLower())<0){
            //如果超出预警值范围，则发送预警消息
            sendAlarmMessage(point,value,4);
        }
    }
```

### 4.3 设备报警合并算法

**算法背景：**
在设备运行过程中，监测数据可能在阈值附近频繁波动，导致短时间内产生大量重复报警信息。这种"报警风暴"会淹没重要信息，降低监控效率。报警合并算法通过智能合并相关报警，提供清晰、连续的异常状态跟踪。

**合并算法实现思路：**

**1. 首次触发创建记录**

当监测点首次触发预警或报警时，创建新的报警记录

记录触发时间、有效值、报警级别、监测点信息

启动合并时间窗口（默认15分钟）

**2. 合并窗口内数据处理**

**数据追加**：在合并窗口内，新的异常监测数据被追加到同一报警记录的监控日志中

**级别升级**：如果原记录为预警级别，后续数据达到报警阈值，则将记录升级为报警级别

**3. 状态恢复判断**

**状态数据恢复**：当监测数据在合并窗口内持续低于预警阈值，系统判定状态恢复正常

**超时恢复**：当超过合并时间窗口后，则自动恢复

其具体实现思路为当有异常值时，先查询Redis中有没有对应的记录id，如果有记录id则新增日志数据，无记录id则新建。当无异常值时，检查Redis中是否有监测点异常记录id，如果有则记录恢复值。

            Object o = redisClient.get(String.format("%s%d", MONITOR_POINT_NAME_HEAD, point.getId()));

                    alert.setRecoveryTime(new Date());

    private void sendAlarmMessage(EquipmentMonitorPoint point, Double value, int i) {
        log.info("发送报警消息，报警类型：{}，报警值：{}，报警点：{}",i,value,point);
        //如果之前有报警事件，则需要合并报警事件
        Object o = redisClient.get(String.format("%s%d", MONITOR_POINT_NAME_HEAD, point.getId()));
        if (o!=null){
            Integer paId = (Integer) o;
            MonitorPointAlert alert = alertMapper.selectById(paId);
            if (alert!=null&&"0".equals(alert.getHandleState())){
                //如果之前有报警事件，且事件未被处理，则需要合并报警事件
                alert.setMonitorLog(String.format("%s\r\n 报警时间:%s 报警值:%3f;",
                        alert.getMonitorLog(), DateUtil.format(new Date(), "yyyy-MM-dd HH:mm:ss"), value));
                alertMapper.updateById(alert);
            }else{
                //如果被处理，则删除redis中的缓存，后续如果报警，则重新再添加一个报警事件
                redisClient.delete(String.format("%s%d",MONITOR_POINT_NAME_HEAD,point.getId()));
            }
        }else{
            String content=point.getPointName();
            if (i==1){
                content+="超上限报警";
            }else if (i==2){
                content+="超下限报警";
            }else if (i==3){
                content+="超上限预警";
            }else if (i==4){
                content+="超下限预警";
            }
            //如果之前没有报警事件，则需要创建报警事件
            MonitorPointAlert pointAlert = new MonitorPointAlert();

            pointAlert.setEquipmentId(point.getEquipmentId());

            pointAlert.setAlertType(i==1||i==2?"1":"0");
            pointAlert.setMonitorAlertType("1");
            alertMapper.insert(pointAlert);
            redisClient.set(String.format("%s%d",MONITOR_POINT_NAME_HEAD,point.getId()),pointAlert.getId(),15, TimeUnit.MINUTES);
        }

    /*
    * 更新设备信息，包括新增，修改，删除
    * 类型：add：新增，update：修改，delete：删除
    */
    public void updateEquipmentAssets(EquipmentAssets equipmentAssets, UpdateOperationEnum type) {
        if(equipmentAssets==null||equipmentAssets.getAssetId()==null||equipmentAssets.getPlatformEqCode()==null) return;
        //更新时，存在状态变更的情况，可分为以下四种情况
        // 开->开：走更新操作
        // 开->关：走删除操作
        // 关->开：走新增操作
        // 关->关：直接返回
        if(type== UpdateOperationEnum.UPDATE){
            //先默认状态为开，查询Map无数据，说明设备未开启
            String oldStatus = "0";
            List<EquipmentMonitorPoint> points = equipmentMonitorPointMap.get(equipmentAssets.getAssetId());
            if(points!=null){
                oldStatus = "0";
                //关->开
                if(equipmentAssets.getOpenStatus()=="1"){
                    type= UpdateOperationEnum.ADD;
                }
                else {
                    return;
                }
            }else{
                //开->关
                if(equipmentAssets.getOpenStatus()=="0"){
                    type= UpdateOperationEnum.DELETE;
                }
            }
        }
        //对Map进行操作
        if (type== UpdateOperationEnum.ADD) {
            equipmentAssetsMap.put(equipmentAssets.getPlatformEqCode(),equipmentAssets);
        } else if (type== UpdateOperationEnum.UPDATE) {
            equipmentAssetsMap.put(equipmentAssets.getPlatformEqCode(),equipmentAssets);
        } else if (type== UpdateOperationEnum.DELETE) {
            equipmentAssetsMap.remove(equipmentAssets.getPlatformEqCode());
            equipmentMonitorPointMap.remove(equipmentAssets.getAssetId());
        }
    }
    /*
    * 更新设备监测点信息
    */
    public void updateEquipmentMonitorPoint(EquipmentMonitorPoint equipmentMonitorPoint, UpdateOperationEnum type) {
        //先判断设备监测点状态变化
        String oldStatus = "0";
        List<EquipmentMonitorPoint> points = equipmentMonitorPointMap.get(equipmentMonitorPoint.getEquipmentId());
        if(points!=null){
            oldStatus = "0";
            //关->开
            if(equipmentMonitorPoint.getStatus()=="1"){
                type= UpdateOperationEnum.ADD;
            }
            else {
                return;
            }
        }else{
            //开->关
            if(equipmentMonitorPoint.getStatus()=="0"){
                type= UpdateOperationEnum.DELETE;
            }
        }
        if(type== UpdateOperationEnum.ADD){
            List<EquipmentMonitorPoint> equipmentMonitorPointList = equipmentMonitorPointMap.get(equipmentMonitorPoint.getEquipmentId());
            if(equipmentMonitorPointList!=null){
                equipmentMonitorPointList.add(equipmentMonitorPoint);
            }
        } else if (type == UpdateOperationEnum.DELETE) {
            List<EquipmentMonitorPoint> equipmentMonitorPointList = equipmentMonitorPointMap.get(equipmentMonitorPoint.getEquipmentId());
            if(equipmentMonitorPointList!=null){
                equipmentMonitorPointList.removeIf(e->e.getEquipmentId()==equipmentMonitorPoint.getId());
            }
        } else if (type == UpdateOperationEnum.UPDATE) {
            List<EquipmentMonitorPoint> equipmentMonitorPointList = equipmentMonitorPointMap.get(equipmentMonitorPoint.getEquipmentId());
            if(equipmentMonitorPointList!=null){
                equipmentMonitorPointList.removeIf(e->e.getEquipmentId()==equipmentMonitorPoint.getId());
                equipmentMonitorPointList.add(equipmentMonitorPoint);
                equipmentMonitorPointMap.put(equipmentMonitorPoint.getEquipmentId(),equipmentMonitorPointList);
            }
        }
    }

//            如果设备列表不存在，则表示设备的不存在或未开启，则之间跳过

     * 更新设备信息，包括新增，修改，删除
     * 类型：add：新增，update：修改，delete：删除

    public void updateEquipmentAssets(EquipmentAssets equipmentAssets, UpdateOperationEnum type) {
        if(equipmentAssets==null||equipmentAssets.getAssetId()==null||equipmentAssets.getPlatformEqCode()==null) return;
        //更新时，存在状态变更的情况，可分为以下四种情况
        // 开->开：走更新操作
        // 开->关：走删除操作
        // 关->开：走新增操作
        // 关->关：直接返回
        if(type== UpdateOperationEnum.UPDATE){
            //先默认状态为开，查询Map无数据，说明设备未开启
            String oldStatus = "0";
            List<EquipmentMonitorPoint> points = equipmentMonitorPointMap.get(equipmentAssets.getAssetId());
            if(points!=null){
                oldStatus = "0";
                //关->开
                if(equipmentAssets.getOpenStatus()=="1"){
                    type= UpdateOperationEnum.ADD;
                }
                else {
                    return;
                }
            }else{
                //开->关
                if(equipmentAssets.getOpenStatus()=="0"){
                    type= UpdateOperationEnum.DELETE;
                }
            }
        }
        //对Map进行操作
        if (type== UpdateOperationEnum.ADD) {
            equipmentAssetsMap.put(equipmentAssets.getPlatformEqCode(),equipmentAssets);
        } else if (type== UpdateOperationEnum.UPDATE) {
            equipmentAssetsMap.put(equipmentAssets.getPlatformEqCode(),equipmentAssets);
        } else if (type== UpdateOperationEnum.DELETE) {
            equipmentAssetsMap.remove(equipmentAssets.getPlatformEqCode());
            equipmentMonitorPointMap.remove(equipmentAssets.getAssetId());
        }
    }

    public void updateEquipmentMonitorPoint(EquipmentMonitorPoint equipmentMonitorPoint, UpdateOperationEnum type) {
        //先判断设备监测点状态变化
        String oldStatus = "0";
        List<EquipmentMonitorPoint> points = equipmentMonitorPointMap.get(equipmentMonitorPoint.getEquipmentId());
        if(points!=null){
            oldStatus = "0";
            //关->开
            if(equipmentMonitorPoint.getStatus()=="1"){
                type= UpdateOperationEnum.ADD;
            }
            else {
                return;
            }
        }else{
            //开->关
            if(equipmentMonitorPoint.getStatus()=="0"){
                type= UpdateOperationEnum.DELETE;
            }
        }
        if(type== UpdateOperationEnum.ADD){
            List<EquipmentMonitorPoint> equipmentMonitorPointList = equipmentMonitorPointMap.get(equipmentMonitorPoint.getEquipmentId());
            if(equipmentMonitorPointList!=null){
                equipmentMonitorPointList.add(equipmentMonitorPoint);
            }
        } else if (type == UpdateOperationEnum.DELETE) {
            List<EquipmentMonitorPoint> equipmentMonitorPointList = equipmentMonitorPointMap.get(equipmentMonitorPoint.getEquipmentId());
            if(equipmentMonitorPointList!=null){
                equipmentMonitorPointList.removeIf(e->e.getEquipmentId()==equipmentMonitorPoint.getId());
            }
        } else if (type == UpdateOperationEnum.UPDATE) {
            List<EquipmentMonitorPoint> equipmentMonitorPointList = equipmentMonitorPointMap.get(equipmentMonitorPoint.getEquipmentId());
            if(equipmentMonitorPointList!=null){
                equipmentMonitorPointList.removeIf(e->e.getEquipmentId()==equipmentMonitorPoint.getId());
                equipmentMonitorPointList.add(equipmentMonitorPoint);
                equipmentMonitorPointMap.put(equipmentMonitorPoint.getEquipmentId(),equipmentMonitorPointList);
            }
        }
    }

    /*
     * 根据设备信息与监测点设置进行数据检测
     * */
    private void processPoint(DeviceReportDTO data, EquipmentMonitorPoint point) {
        //根据DTO中的数据与监测点数据是否匹配，判断是否需要进行数据处理
        String s = data.getProperties().get(point.getDeviceCode());
        if(s!=null){
            MonitorValue pointValue = new MonitorValue();
            pointValue.setEquipmentId(point.getEquipmentId());
            pointValue.setMonitorPointId(point.getId());
            pointValue.setMonitorData(s);
            pointValue.setMonitorTime(new Date());
            monitorPointValueMapper.insert(pointValue);
            // 数值预警处理，先判断是否为数字
            if (!s.matches("-?\\d+(\\.\\d+)?")) {
                return;
            }
            Double dataValue = Double.valueOf(s);

            //如果匹配，则先判断检测时间为0的情况
            if (point.getRangeTime()==null||point.getRangeTime()==0){
                //如果检测时间为0，则直接进行数据处理
                checkPoint(point,dataValue);
            }else{
                // 如果时间不为0，则需要先计算，再存入Redis，如果先存再计算，可能出现存上去，get不返回数据的情况
                Set<String> set = redisClient.getKeysByPrefix(String.format("%s%d_", PROPERTY_NAME_HEAD, point.getId()));
                switch (point.getStatisticalType()) {
                    case "1":
                        // 平均值计算（使用迭代器遍历）
                        Iterator<String> avgIterator = set.iterator();
                        while (avgIterator.hasNext()) {
                            String key = avgIterator.next();
                            Object o = redisClient.get(key);
                            if (o == null) {
                                avgIterator.remove(); // 迭代器安全删除，避免并发修改异常
                                continue;
                            }
                            // 增加类型判断，避免ClassCastException
                            if (o instanceof Double) {
                                dataValue += (Double) o;
                            }
                        }
                        dataValue /= (set.size() + 1); // 包含当前数据的平均值
                        break;

                    case "2":
                        // 最大值计算（使用迭代器遍历）
                        Iterator<String> maxIterator = set.iterator();
                        while (maxIterator.hasNext()) {
                            String key = maxIterator.next();
                            Object o = redisClient.get(key);
                            if (o == null) {
                                maxIterator.remove(); // 迭代器安全删除
                                continue;
                            }
                            if (o instanceof Double) {
                                dataValue = Math.max(dataValue, (Double) o);
                            }
                        }
                        break;

                    case "3":
                        // 最小值计算（使用迭代器遍历）
                        Iterator<String> minIterator = set.iterator();
                        while (minIterator.hasNext()) {
                            String key = minIterator.next();
                            Object o = redisClient.get(key);
                            if (o == null) {
                                minIterator.remove(); // 迭代器安全删除
                                continue;
                            }
                            if (o instanceof Double) {
                                dataValue = Math.min(dataValue, (Double) o);
                            }
                        }
                        break;

                    case "4":
                        // 总和计算（使用迭代器遍历）
                        Iterator<String> sumIterator = set.iterator();
                        while (sumIterator.hasNext()) {
                            String key = sumIterator.next();
                            Object o = redisClient.get(key);
                            if (o == null) {
                                sumIterator.remove(); // 迭代器安全删除
                                continue;
                            }
                            if (o instanceof Double) {
                                dataValue += (Double) o;
                            }
                        }
                        break;
                }
                redisClient.set(String.format("%s%d_%s",PROPERTY_NAME_HEAD,point.getId(), UUID.randomUUID()),
                        dataValue,
                        point.getRangeTime(),
                        TimeUnit.SECONDS);
                log.info("监测点id为{}的监测数据为{}",point.getId(),dataValue);
                checkPoint(point,dataValue);

            }
        }
        return;
    }
    /*
     * 监测数据是否超出预警值或者报警值的范围
     */
    private void checkPoint(EquipmentMonitorPoint point, Double value){
        if (point.getAlarmUpper()!=null&&value>point.getAlarmUpper()){
            //如果超出报警值范围，则发送报警消息
            sendAlarmMessage(point,value,1);
        }
        else if (point.getAlarmLower()!=null&&value.compareTo(point.getAlarmLower())<0){
            //如果超出报警值范围，则发送报警消息
            sendAlarmMessage(point,value,2);
        }
        else if (point.getWarnUpper()!=null&&value.compareTo(point.getWarnUpper())>0){
            //如果超出预警值范围，则发送预警消息
            sendAlarmMessage(point,value,3);
        }
        else if (point.getWarnLower()!=null&&value.compareTo(point.getWarnLower())<0){
            //如果超出预警值范围，则发送预警消息
            sendAlarmMessage(point,value,4);
        }else{
            // 如果都没有超出，则说明当前正常，可以是一直正常，也可以是从报警中恢复过来的,如果查询到之前的报警信息，则添加恢复值，并更新恢复时间
            Object o = redisClient.get(String.format("%s%d", MONITOR_POINT_NAME_HEAD, point.getId()));
            if (o!=null){
                Integer paId = (Integer) o;
                MonitorPointAlert alert = alertMapper.selectById(paId);
                if (alert!=null){
                    alert.setRecoveryData(value.toString());
                    alert.setRecoveryTime(new Date());
                    alertMapper.updateById(alert);
                    redisClient.delete(String.format("%s%d",MONITOR_POINT_NAME_HEAD,point.getId()));
                }
            }
        }
    }
    /*
        通用报警事件处理，需要考虑到事件合并，否则可能会出现许多条报警事件
    */
    private void sendAlarmMessage(EquipmentMonitorPoint point, Double value, int i) {
        log.info("发送报警消息，报警类型：{}，报警值：{}，报警点：{}",i,value,point);
        //如果之前有报警事件，则需要合并报警事件
        Object o = redisClient.get(String.format("%s%d", MONITOR_POINT_NAME_HEAD, point.getId()));
        if (o!=null){
            Integer paId = (Integer) o;
            MonitorPointAlert alert = alertMapper.selectById(paId);
            if (alert!=null&&"0".equals(alert.getHandleState())){
                //如果之前有报警事件，且事件未被处理，则需要合并报警事件
                alert.setMonitorLog(String.format("%s\r\n 报警时间:%s 报警值:%3f;",
                        alert.getMonitorLog(), DateUtil.format(new Date(), "yyyy-MM-dd HH:mm:ss"), value));
                alertMapper.updateById(alert);
            }else{
                //如果被处理，则删除redis中的缓存，后续如果报警，则重新再添加一个报警事件
                redisClient.delete(String.format("%s%d",MONITOR_POINT_NAME_HEAD,point.getId()));
            }
        }else{
            String content=point.getPointName();
            if (i==1){
                content+="超上限报警";
            }else if (i==2){
                content+="超下限报警";
            }else if (i==3){
                content+="超上限预警";
            }else if (i==4){
                content+="超下限预警";
            }
            //如果之前没有报警事件，则需要创建报警事件
            MonitorPointAlert pointAlert = new MonitorPointAlert();
            pointAlert.setMonitorPointId(point.getId());
            pointAlert.setEquipmentId(point.getEquipmentId());
            pointAlert.setMonitorData(value.toString());
            pointAlert.setContent(content);
            pointAlert.setMonitorLog(String.format("报警时间:%s 报警值:%s;",
                    DateUtil.format(new Date(), "yyyy-MM-dd HH:mm:ss"), value));
            pointAlert.setCreateTime(new Date());
            pointAlert.setHandleState("0");
            pointAlert.setAlertType(i==1||i==2?"1":"0");
            pointAlert.setMonitorAlertType("1");
            alertMapper.insert(pointAlert);
            redisClient.set(String.format("%s%d",MONITOR_POINT_NAME_HEAD,point.getId()),pointAlert.getId(),15, TimeUnit.MINUTES);
        }
    }
