**3.2 Netty服务器设计**

在设计Netty服务器时，需要考虑到通信协议、服务器搭建、数据处理与TCP连接管理等问题。

**通信协议**：在设备客户端与服务端进行通信时，通常采用4字节长度+实际数据的通信协议进行通信。TCP通信是通过比特流进行通信，在通信时所有的数据都是通过Byte进行传输。。如果不规定好传输数据的大小，就容易造成粘包和拆包的问题。

例如发送的JSON字符串为：“{"id":"device_001","status":"online"}”，则转为比特流数据为：[7B 22 69 64 22 3A 22 64 65 76 69 63 65 5F 30 30 31 22 2C 22 73 74 61 74 75 73 22 3A 22 6F 6E 6C 69 6E 65 22 7D]。如果同时发送两次数据，则服务端可能会接收到以下两帧数据：

[7B 22 69 64 22 3A 22 64 65 76 69 63 65 5F 30 30 31 22 2C 22 73 74 61 74 75 73 22 3A 22 6F 6E 6C 69 6E 65 22 7D7B 22 69 64 22 3A 22 64 65 76 ]

[69 63 65 5F 30 30 31 22 2C 22 73 74 61 74 75 73 22 3A 22 6F 6E 6C 69 6E 65 22 7D]

此时如果直接将数据进行拼接解析，则会解析出两个JSON字符串的拼接，无法进行JSON解析。

通过在前面加上4比特大小的长度数据，则发送的数据格式为：[00 00 00 23] [7B 22 69 64 22 3A 22 64 65 76 69 63 65 5F 30 30 31 22 2C 22 73 74 61 74 75 73 22 3A 22 6F 6E 6C 69 6E 65 22 7D]，服务端每次都会先读出前4比特的数据获取数据长度，再根据数据长度按需读取其他数据，防止JSON解析问题。

**TCP连接管理**：服务器在与设备建立连接时，会与多个设备建立TCP连接，所以需要创建一个TCP连接池来管理TCP连接，该连接池需包括获取连接对象和连接信息、关闭连接、获取连接数量、发送消息和广播消息。

**数据处理：**在建立Netty服务器后，需要处理建立连接、断开连接和数据传输事件，可创建一个单独的Handle处理Netty服务器上发生的以上事件内容。

**3.2.2 数据处理：**

创建一个数据处理器来专门处理TCP连接建立、断开和数据请求事件。

当TCP连接建立时，由于设备还未发送第一次数据，没有任何数据信息，所以无法分辨是哪个设备所属的TCP连接，可在Redis中存储上一条数据，键值为“TCP客户端ID”：0。0表示该客户端还未匹配设备。

```typescript

    */

        //添加设备连接记录
        redisClient.set(CLIENT_NAME_HEAD+clientId,0);
    }
```

当数据发送过来时，进行设备数据处理，需要处理设备上线和存储设备数据。在执行数据处理时需注意，在多设备同时发送数据时，执行数据会被频繁调用，需要通过线程池来执行该代码，以提高执行效率。注意在使用线程池前，需要配置“DataProcessTaskExecutor”线程池。

在处理设备上线时，首先根据DTO中的code匹配设备，如果没有匹配则返回null。如果匹配后再检查TCP客户端是否已经处理过上线操作（Redis中的值是否为0），如果未处理则处理上线操作。

当处理完成上线操作后，并且设备已经匹配，直接将DTO数据转换并存入数据库。

**3.2.3 Netty服务器搭建**

创建并启动Netty服务器类，在该类启动时，创建Netty服务，实现服务线程组定义、TCP连接设置、数据帧解析设置、自定义处理器等内容。需要注意的是Netty服务需要通过创建一个新线程来起启动，如果通过主线程启动，则会将SpringBoot启动线程堵塞，使其无法启动服务。

在本项目中，定义Netty服务端口为8888。

```java
   private int TCP_PORT=8888;

    @PostConstruct
    public void startServer() {
        // 创建独立线程用于启动Netty服务器，避免阻塞Spring容器初始化（因Netty启动含阻塞操作）
        nettyServerThread = new Thread(() -> {
            try {
                // 初始化boss线程组：负责接收客户端连接，此处指定1个线程（通常无需多个）
                bossGroup = new NioEventLoopGroup(1);
                // 初始化worker线程组：负责处理已连接客户端的IO操作，默认线程数为CPU核心数×2
                workerGroup = new NioEventLoopGroup();

                // 构建Netty服务端启动器
                ServerBootstrap bootstrap = new ServerBootstrap()
                        // 绑定boss和worker线程组
                        .group(bossGroup, workerGroup)
                        // 指定服务端通道类型为NIO（非阻塞IO，适合高并发场景）
                        .channel(NioServerSocketChannel.class)
                        // 设置TCP参数：SO_BACKLOG表示未完成三次握手的连接队列大小
                        .option(ChannelOption.SO_BACKLOG, 100)
                        // 设置客户端连接参数：SO_KEEPALIVE启用TCP心跳机制，检测死连接
                        .childOption(ChannelOption.SO_KEEPALIVE, true)
                        // 配置新连接的处理器初始化器（每个客户端连接建立时都会执行initChannel）
                        .childHandler(new ChannelInitializer<SocketChannel>() {
                            @Override
                            protected void initChannel(SocketChannel ch) throws Exception {
                                // 获取当前通道的处理器流水线（责任链模式，按添加顺序执行）
                                ChannelPipeline pipeline = ch.pipeline();

                                // 添加长度字段解码器：解决TCP粘包/拆包问题
                                // 帧格式约定为 [4字节长度][JSON数据]，参数对应协议格式配置
                                pipeline.addLast(new LengthFieldBasedFrameDecoder(
                                        MAX_FRAME_LENGTH,       // 最大帧长度（防止超大报文攻击）
                                        LENGTH_FIELD_OFFSET,   // 长度字段在帧中的起始偏移量
                                        LENGTH_FIELD_LENGTH,   // 长度字段占用的字节数（此处为4字节int）
                                        LENGTH_ADJUSTMENT,     // 长度调整值（通常为0，若长度包含自身则需修正）
                                        INITIAL_BYTES_TO_STRIP // 解码后跳过的字节数（跳过长度字段，只保留数据）
                                ));

                                // 添加字符串解码器：将字节流转换为UTF-8编码的字符串
                                pipeline.addLast(new StringDecoder(CharsetUtil.UTF_8));
                                // 添加字符串编码器：将字符串转换为UTF-8编码的字节流
                                pipeline.addLast(new StringEncoder(CharsetUtil.UTF_8));

                                // 添加自定义业务处理器，传入依赖的连接池、JSON工具和业务服务
                                pipeline.addLast(new TcpServerHandler(
                                        tcpClientPool, // 客户端连接池（管理所有TCP连接）
                                        objectMapper, // JSON序列化工具
                                        equipmentAssetsDataProcessHandle // 业务处理服务
                                ));
                            }
                        });

                // 绑定监听端口并同步等待绑定完成（阻塞操作，直到端口绑定成功）
                ChannelFuture future = bootstrap.bind(TCP_PORT).sync();
                log.info("TCP Netty Server 启动成功，监听端口：{}", TCP_PORT);
                // 阻塞等待服务器通道关闭（即保持服务器运行，直到主动关闭）
                future.channel().closeFuture().sync();

            } catch (InterruptedException e) {
                log.error("TCP Netty Server 启动异常或被中断", e);
                // 恢复线程中断状态，便于上层逻辑感知中断事件
                Thread.currentThread().interrupt();
            } finally {
                // 优雅关闭线程组，释放资源（无论启动成功与否均执行）
                if (bossGroup != null) bossGroup.shutdownGracefully();
                if (workerGroup != null) workerGroup.shutdownGracefully();
                // 服务器关闭时清理所有客户端连接，避免资源泄漏
                tcpClientPool.removeAll();
            }
        }, "Netty-TCP-Server-Thread"); // 线程命名，便于日志和监控识别

        // 启动Netty服务器线程
        nettyServerThread.start();
    }
```

TcpServerHandler是自定义的TCP数据处理器，需继承SimpleChannelInboundHandler，并实现客户端连接和断开处理、数据解析和发送、数据合法性校验等内容。

```swift
    /**
     * 自定义ChannelHandler：处理Netty的IO事件，使用TCPClientPool管理连接
     */
    public class TcpServerHandler extends SimpleChannelInboundHandler<String> {
        private final TCPClientPool tcpClientPool;
        private final ObjectMapper objectMapper;
        private final EquipmentAssetsDataProcessHandle equipmentAssetsDataProcessHandle;
        // 构造函数注入所有依赖
        public TcpServerHandler(TCPClientPool tcpClientPool,
                                ObjectMapper objectMapper, EquipmentAssetsDataProcessHandle equipmentAssetsDataProcessHandle) {
            this.tcpClientPool = tcpClientPool;
            this.objectMapper = objectMapper;
            this.equipmentAssetsDataProcessHandle = equipmentAssetsDataProcessHandle;
        }
        @Override
        public void channelActive(ChannelHandlerContext ctx) throws Exception {
            Channel channel = ctx.channel();
            String clientId = getClientId(channel);
            // 使用TCPClientPool注册客户端
            tcpClientPool.register(clientId, channel);
            log.info("新客户端连接：{}，当前连接数：{}", clientId, tcpClientPool.getConnectionCount());
            equipmentAssetsDataProcessHandle.deviceConnect(clientId);
        }
        @Override
        protected void channelRead0(ChannelHandlerContext ctx, String receivedData) throws Exception {
            Channel channel = ctx.channel();
            String clientId = getClientId(channel);

            try {
                // 使用Jackson的流式API处理JSON数据
                JsonParser parser = objectMapper.getFactory().createParser(receivedData);
                DeviceReportDTO reportDTO = objectMapper.readValue(parser, DeviceReportDTO.class);
                // 数据校验
                validateReportData(reportDTO, clientId);
                // 处理设备数据
                equipmentAssetsDataProcessHandle.processEquipmentAssetsData(reportDTO, clientId);
                // 构建响应
                String response = String.format("{\"status\":\"success\", \"message\":\"数据已接收\", \"timestamp\":%d}",
                        System.currentTimeMillis());
                sendResponse(channel, response);
            } catch (JsonProcessingException e) {
                log.error("客户端[{}]数据解析失败：{}", clientId, receivedData, e);
                sendResponse(channel, "{\"status\":\"error\", \"message\":\"数据格式错误\"}");
            } catch (IllegalArgumentException e) {
                log.error("客户端[{}]数据验证失败：{}", clientId, e.getMessage());
                sendResponse(channel, String.format("{\"status\":\"error\", \"message\":\"%s\"}", e.getMessage()));
            } catch (Exception e) {
                log.error("客户端[{}]数据处理异常", clientId, e);
                sendResponse(channel, "{\"status\":\"error\", \"message\":\"服务器处理失败\"}");
            }
        }
        @Override
        public void channelInactive(ChannelHandlerContext ctx) throws Exception {
            Channel channel = ctx.channel();
            String clientId = getClientId(channel);
            // 使用TCPClientPool移除客户端
            tcpClientPool.remove(clientId);
            log.info("客户端[{}]连接断开，当前连接数：{}", clientId, tcpClientPool.getConnectionCount());
            equipmentAssetsDataProcessHandle.deviceOffline(clientId);
        }
        @Override
        public void exceptionCaught(ChannelHandlerContext ctx, Throwable cause) throws Exception {
            Channel channel = ctx.channel();
            String clientId = getClientId(channel);
            log.error("客户端[{}]连接异常", clientId, cause);
            // 移除异常客户端
            tcpClientPool.remove(clientId);
            equipmentAssetsDataProcessHandle.deviceOffline(clientId);
            ctx.close();
        }
        /**
         * 发送响应给客户端，添加长度前缀
         */
        private void sendResponse(Channel channel, String response) {
            try {
                byte[] responseBytes = response.getBytes(CharsetUtil.UTF_8);
                ByteBuf buffer = Unpooled.buffer(4 + responseBytes.length);
                buffer.writeInt(responseBytes.length);
                buffer.writeBytes(responseBytes);
                channel.writeAndFlush(buffer);
            } catch (Exception e) {
                log.error("发送响应失败", e);
            }
        }

        /**
         * 验证上报数据的合法性
         */
        private void validateReportData(DeviceReportDTO reportDTO, String clientId) {
            if (reportDTO.getId() == null || reportDTO.getId().trim().isEmpty()) {
                throw new IllegalArgumentException("设备ID不能为空");
            }
            if (reportDTO.getProperties() == null || reportDTO.getProperties().isEmpty()) {
                throw new IllegalArgumentException("设备属性不能为空");
            }
        }

        private String getClientId(Channel channel) {
            return channel.remoteAddress().toString().replace("/", "");
        }
    }
```

```typescript
@Component
public class TCPClientPool {
    private static final Logger log = LoggerFactory.getLogger(TCPClientPool.class);

    // 存储客户端连接信息
    private final Map<String, Channel> clientMap = new ConcurrentHashMap<>();
    private final Map<String, ClientInfo> clientInfoMap = new ConcurrentHashMap<>();

    /**
     * 注册客户端连接
     */
    public void register(String clientId, Channel channel) {
        clientMap.put(clientId, channel);
        clientInfoMap.put(clientId, new ClientInfo(clientId, channel, System.currentTimeMillis()));
        log.info("客户端[{}]注册成功，当前连接数：{}", clientId, clientMap.size());
    }

    /**
     * 获取客户端连接
     */
    public Channel getClient(String clientId) {
        return clientMap.get(clientId);
    }

    /**
     * 移除客户端连接
     */
    public void remove(String clientId) {
        Channel channel = clientMap.remove(clientId);
        clientInfoMap.remove(clientId);
        if (channel != null && channel.isActive()) {
            channel.close();
        }
        log.info("客户端[{}]移除成功，当前连接数：{}", clientId, clientMap.size());
    }

    /**
     * 移除所有客户端连接
     */
    public void removeAll() {
        log.info("开始移除所有客户端连接，总数：{}", clientMap.size());
        for (String clientId : new ArrayList<>(clientMap.keySet())) {
            remove(clientId);
        }
        clientMap.clear();
        clientInfoMap.clear();
    }

    /**
     * 获取所有客户端ID
     */
    public Set<String> getAllClientIds() {
        return new HashSet<>(clientMap.keySet());
    }

    /**
     * 获取连接数量
     */
    public int getConnectionCount() {
        return clientMap.size();
    }

    /**
     * 发送消息到指定客户端
     */
    public boolean sendMessage(String clientId, String message) {
        Channel channel = clientMap.get(clientId);
        if (channel != null && channel.isActive()) {
            try {
                // 添加长度前缀
                byte[] messageBytes = message.getBytes(StandardCharsets.UTF_8);
                ByteBuf buffer = Unpooled.buffer(4 + messageBytes.length);
                buffer.writeInt(messageBytes.length);
                buffer.writeBytes(messageBytes);

                channel.writeAndFlush(buffer);
                log.debug("消息发送成功到客户端[{}]", clientId);
                return true;
            } catch (Exception e) {
                log.error("发送消息到客户端[{}]失败", clientId, e);
                remove(clientId);
            }
        }
        return false;
    }

    /**
     * 广播消息到所有客户端
     */
    public void broadcast(String message) {
        for (String clientId : getAllClientIds()) {
            sendMessage(clientId, message);
        }
    }

    /**
     * 获取客户端连接信息
     */
    public Map<String, Object> getClientInfo(String clientId) {
        ClientInfo info = clientInfoMap.get(clientId);
        if (info != null) {
            Map<String, Object> result = new HashMap<>();
            result.put("clientId", info.getClientId());
            result.put("connectTime", new Date(info.getConnectTime()));
            result.put("active", info.getChannel() != null && info.getChannel().isActive());
            result.put("remoteAddress", info.getChannel() != null ?
                    info.getChannel().remoteAddress().toString() : "未知");
            return result;
        }
        return Collections.emptyMap();
    }

    /**
     * 获取所有客户端信息
     */
    public Map<String, Map<String, Object>> getAllClientInfos() {
        Map<String, Map<String, Object>> result = new HashMap<>();
        for (String clientId : clientInfoMap.keySet()) {
            result.put(clientId, getClientInfo(clientId));
        }
        return result;
    }

    /**
     * 客户端信息内部类
     */
    private static class ClientInfo {
        private final String clientId;
        private final Channel channel;
        private final long connectTime;

        public ClientInfo(String clientId, Channel channel, long connectTime) {
            this.clientId = clientId;
            this.channel = channel;
            this.connectTime = connectTime;
        }

        public String getClientId() { return clientId; }
        public Channel getChannel() { return channel; }
        public long getConnectTime() { return connectTime; }
    }
}
```

TCPNettyServer：

```java
@Component
public class TCPNettyServer {
    private static final Logger log = LoggerFactory.getLogger(TCPNettyServer.class);

    private int TCP_PORT=8888;
    // 配置参数
    private EventLoopGroup bossGroup;
    private EventLoopGroup workerGroup;
    // 移除内部的 clientChannels，改为使用 TCPClientPool
    @Autowired
    private TCPClientPool tcpClientPool;
    private Thread nettyServerThread;
    // 注入依赖
    @Autowired
    private ObjectMapper objectMapper;
    @Autowired
    private EquipmentAssetsDataProcessHandle equipmentAssetsDataProcessHandle;

    // 定义最大帧长度为1MB
    private static final int MAX_FRAME_LENGTH = 1024 * 1024;
    private static final int LENGTH_FIELD_OFFSET = 0;
    private static final int LENGTH_FIELD_LENGTH = 4;
    private static final int LENGTH_ADJUSTMENT = 0;
    private static final int INITIAL_BYTES_TO_STRIP = 4;
    /**
     * 服务器启动方法，使用@PostConstruct注解确保在当前Bean初始化完成后自动执行
     */
    @PostConstruct
    public void startServer() {
        // 创建独立线程用于启动Netty服务器，避免阻塞Spring容器初始化（因Netty启动含阻塞操作）
        nettyServerThread = new Thread(() -> {
            try {
                // 初始化boss线程组：负责接收客户端连接，此处指定1个线程（通常无需多个）
                bossGroup = new NioEventLoopGroup(1);
                // 初始化worker线程组：负责处理已连接客户端的IO操作，默认线程数为CPU核心数×2
                workerGroup = new NioEventLoopGroup();

                // 构建Netty服务端启动器
                ServerBootstrap bootstrap = new ServerBootstrap()
                        // 绑定boss和worker线程组
                        .group(bossGroup, workerGroup)
                        // 指定服务端通道类型为NIO（非阻塞IO，适合高并发场景）
                        .channel(NioServerSocketChannel.class)
                        // 设置TCP参数：SO_BACKLOG表示未完成三次握手的连接队列大小
                        .option(ChannelOption.SO_BACKLOG, 100)
                        // 设置客户端连接参数：SO_KEEPALIVE启用TCP心跳机制，检测死连接
                        .childOption(ChannelOption.SO_KEEPALIVE, true)
                        // 配置新连接的处理器初始化器（每个客户端连接建立时都会执行initChannel）
                        .childHandler(new ChannelInitializer<SocketChannel>() {
                            @Override
                            protected void initChannel(SocketChannel ch) throws Exception {
                                // 获取当前通道的处理器流水线（责任链模式，按添加顺序执行）
                                ChannelPipeline pipeline = ch.pipeline();

                                // 添加长度字段解码器：解决TCP粘包/拆包问题
                                // 帧格式约定为 [4字节长度][JSON数据]，参数对应协议格式配置
                                pipeline.addLast(new LengthFieldBasedFrameDecoder(
                                        MAX_FRAME_LENGTH,       // 最大帧长度（防止超大报文攻击）
                                        LENGTH_FIELD_OFFSET,   // 长度字段在帧中的起始偏移量
                                        LENGTH_FIELD_LENGTH,   // 长度字段占用的字节数（此处为4字节int）
                                        LENGTH_ADJUSTMENT,     // 长度调整值（通常为0，若长度包含自身则需修正）
                                        INITIAL_BYTES_TO_STRIP // 解码后跳过的字节数（跳过长度字段，只保留数据）
                                ));

                                // 添加字符串解码器：将字节流转换为UTF-8编码的字符串
                                pipeline.addLast(new StringDecoder(CharsetUtil.UTF_8));
                                // 添加字符串编码器：将字符串转换为UTF-8编码的字节流
                                pipeline.addLast(new StringEncoder(CharsetUtil.UTF_8));

                                // 添加自定义业务处理器，传入依赖的连接池、JSON工具和业务服务
                                pipeline.addLast(new TcpServerHandler(
                                        tcpClientPool, // 客户端连接池（管理所有TCP连接）
                                        objectMapper, // JSON序列化工具
                                        equipmentAssetsDataProcessHandle // 业务处理服务
                                ));
                            }
                        });

                // 绑定监听端口并同步等待绑定完成（阻塞操作，直到端口绑定成功）
                ChannelFuture future = bootstrap.bind(TCP_PORT).sync();
                log.info("TCP Netty Server 启动成功，监听端口：{}", TCP_PORT);
                // 阻塞等待服务器通道关闭（即保持服务器运行，直到主动关闭）
                future.channel().closeFuture().sync();

            } catch (InterruptedException e) {
                log.error("TCP Netty Server 启动异常或被中断", e);
                // 恢复线程中断状态，便于上层逻辑感知中断事件
                Thread.currentThread().interrupt();
            } finally {
                // 优雅关闭线程组，释放资源（无论启动成功与否均执行）
                if (bossGroup != null) bossGroup.shutdownGracefully();
                if (workerGroup != null) workerGroup.shutdownGracefully();
                // 服务器关闭时清理所有客户端连接，避免资源泄漏
                tcpClientPool.removeAll();
            }
        }, "Netty-TCP-Server-Thread"); // 线程命名，便于日志和监控识别

        // 启动Netty服务器线程
        nettyServerThread.start();
    }

    /*
     * 停止Netty服务器
     */
    @PreDestroy
    public void stopServer() {
        if (bossGroup != null) bossGroup.shutdownGracefully();
        if (workerGroup != null) workerGroup.shutdownGracefully();
        // 清理所有连接
        tcpClientPool.removeAll();
        log.info("TCP Netty Server 已停止");
    }

    /**
     * 自定义ChannelHandler：处理Netty的IO事件，使用TCPClientPool管理连接
     */
    public class TcpServerHandler extends SimpleChannelInboundHandler<String> {
        private final TCPClientPool tcpClientPool;
        private final ObjectMapper objectMapper;
        private final EquipmentAssetsDataProcessHandle equipmentAssetsDataProcessHandle;
        // 构造函数注入所有依赖
        public TcpServerHandler(TCPClientPool tcpClientPool,
                                ObjectMapper objectMapper, EquipmentAssetsDataProcessHandle equipmentAssetsDataProcessHandle) {

            this.equipmentAssetsDataProcessHandle = equipmentAssetsDataProcessHandle;
        }
        @Override
        public void channelActive(ChannelHandlerContext ctx) throws Exception {
            Channel channel = ctx.channel();
            String clientId = getClientId(channel);
            // 使用TCPClientPool注册客户端
            tcpClientPool.register(clientId, channel);
            log.info("新客户端连接：{}，当前连接数：{}", clientId, tcpClientPool.getConnectionCount());
            equipmentAssetsDataProcessHandle.deviceConnect(clientId);
        }
        @Override
        protected void channelRead0(ChannelHandlerContext ctx, String receivedData) throws Exception {
            Channel channel = ctx.channel();
            String clientId = getClientId(channel);

            try {
                // 使用Jackson的流式API处理JSON数据
                JsonParser parser = objectMapper.getFactory().createParser(receivedData);
                DeviceReportDTO reportDTO = objectMapper.readValue(parser, DeviceReportDTO.class);
                // 数据校验
                validateReportData(reportDTO, clientId);
                // 处理设备数据
                equipmentAssetsDataProcessHandle.processEquipmentAssetsData(reportDTO, clientId);
                // 构建响应
                String response = String.format("{\"status\":\"success\", \"message\":\"数据已接收\", \"timestamp\":%d}",
                        System.currentTimeMillis());
                sendResponse(channel, response);
            } catch (JsonProcessingException e) {
                log.error("客户端[{}]数据解析失败：{}", clientId, receivedData, e);
                sendResponse(channel, "{\"status\":\"error\", \"message\":\"数据格式错误\"}");
            } catch (IllegalArgumentException e) {
                log.error("客户端[{}]数据验证失败：{}", clientId, e.getMessage());
                sendResponse(channel, String.format("{\"status\":\"error\", \"message\":\"%s\"}", e.getMessage()));
            } catch (Exception e) {
                log.error("客户端[{}]数据处理异常", clientId, e);
                sendResponse(channel, "{\"status\":\"error\", \"message\":\"服务器处理失败\"}");
            }
        }
        @Override
        public void channelInactive(ChannelHandlerContext ctx) throws Exception {
            Channel channel = ctx.channel();
            String clientId = getClientId(channel);
            // 使用TCPClientPool移除客户端
            tcpClientPool.remove(clientId);
            log.info("客户端[{}]连接断开，当前连接数：{}", clientId, tcpClientPool.getConnectionCount());
            equipmentAssetsDataProcessHandle.deviceOffline(clientId);
        }
        @Override
        public void exceptionCaught(ChannelHandlerContext ctx, Throwable cause) throws Exception {
            Channel channel = ctx.channel();
            String clientId = getClientId(channel);
            log.error("客户端[{}]连接异常", clientId, cause);
            // 移除异常客户端
            tcpClientPool.remove(clientId);
            equipmentAssetsDataProcessHandle.deviceOffline(clientId);
            ctx.close();
        }
        /**
         * 发送响应给客户端，添加长度前缀
         */
        private void sendResponse(Channel channel, String response) {
            try {
                byte[] responseBytes = response.getBytes(CharsetUtil.UTF_8);
                ByteBuf buffer = Unpooled.buffer(4 + responseBytes.length);
                buffer.writeInt(responseBytes.length);
                buffer.writeBytes(responseBytes);
                channel.writeAndFlush(buffer);
            } catch (Exception e) {
                log.error("发送响应失败", e);
            }
        }

        /**
         * 验证上报数据的合法性
         */
        private void validateReportData(DeviceReportDTO reportDTO, String clientId) {
            if (reportDTO.getId() == null || reportDTO.getId().trim().isEmpty()) {
                throw new IllegalArgumentException("设备ID不能为空");
            }
            if (reportDTO.getProperties() == null || reportDTO.getProperties().isEmpty()) {
                throw new IllegalArgumentException("设备属性不能为空");
            }
        }

        private String getClientId(Channel channel) {
            return channel.remoteAddress().toString().replace("/", "");
        }
    }
```
