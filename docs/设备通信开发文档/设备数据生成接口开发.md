任务指导

### 1．业务背景与设计思路

**真实业务场景分析：**

在智慧工地物联网系统中，各种施工设备（塔机、升降机、环境监测设备等）通过TCP协议与中心服务器建立连接，定期发送设备运行数据。这些数据包含设备状态、运行参数、报警信息等，用于实时监控和设备管理。

**为什么需要数据生成器？**

**开发测试需求**：在真实设备未部署或不可用时，需要模拟设备数据来测试系统功能

**性能验证需求**：需要模拟大量设备并发数据来验证系统处理能力

**业务演示需求**：为客户展示系统功能时需要真实可用的模拟数据

**故障模拟需求**：模拟各种异常情况来测试系统的健壮性

**设备数据的通用格式：**

在本项目中，设备与服务器通信数据的通用结构如下：

```jboss-cli
{
    "code": "设备类型编码",
    "id": "设备唯一标识",
    "properties": {
        "monitorTime": "监测时间", // 设备特定参数...    "status": "设备状态",    "alarms": "报警信息"  
    } 
}
```

### 2．数据生成接口的核心功能设计

数据生成接口需要模拟真实设备的数据特征，因此必须支持在合理范围内生成随机数据。以塔吊为例，回转角度应在0-360度之间，风速通常在1-9级范围内，这些数据不能随意生成，而需要符合工程实际。

设计包含三个核心环节：

- 首先，通过结构化配置定义每个参数的合理范围；
- 其次，基于配置实现数据生成逻辑，确保生成的数据既随机又符合业务规则；
- 最后，提供配置的持久化功能，支持配置的保存、读取和动态更新。

//随机数生成器
function getRandomInRange(min, max, fixed = 2) {
    return Number((Math.random() * (max - min) + min).toFixed(fixed));
}
//时间生成器
function getCurrentTime() {
    return new Date().toLocaleString('zh-CN', {
        year: 'numeric',
        month: '2-digit',
        day: '2-digit',
        hour: '2-digit',
        minute: '2-digit',
        second: '2-digit',
        hour12: false
    }).replace(/\//g, '-');
}
