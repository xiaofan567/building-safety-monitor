任务7-2：风险识别设置

建议工时：

2

任务描述

风险识别设置功能用于管理监控设备信息，提供设备查询、编辑和状态管理。该页面采用响应式布局，包含多条件筛选、数据表格展示、设备编辑交互和分页功能，帮助用户维护设备信息。

知识点：Vue3组合式API、响应式数据管理、API数据交互、条件渲染、表格展示、分页组件、模态框交互、多选标签处理

重点：API数据交互、条件渲染、表格展示、分页组件、设备编辑表单处理

难点：API数据交互、分页组件、AI识别类别的多选标签处理

内容：实现风险识别设置页面的完整功能，包括设备筛选条件、数据表格展示、设备编辑弹框、分页组件和状态管理。

##### 1. 页面整体布局搭建

![img](https://tecs-prod-static.obs.cn-north-1.myhuaweicloud.com/33d31ac81c734ed7acfbaafafebdeeda%2Frichtext%2Fimage%2F20251203%2F34331af9f86443f0ac14b6bb0471d538.png)

风险识别设置页面采用顶部标题+筛选区+表格区+分页区的布局结构

布局实现要点：弹框使用fixed定位和z-index确保显示在最上层；筛选区域采用grid-cols-X实现X列响应式布局。

##### 2. 筛选条件组件实现

![img](https://tecs-prod-static.obs.cn-north-1.myhuaweicloud.com/33d31ac81c734ed7acfbaafafebdeeda%2Frichtext%2Fimage%2F20251203%2F523833cc9dae471d8397479d53705bfe.png)

筛选条件包含设备名称和设备编号

```csharp
javascript
// 筛选条件数据结构
const filters = ref({
  assetName: '',  // 设备名称
```

实现要点：使用input组件进行输入；搜索按钮触发数据重新加载；重置按钮清空筛选条件。
