任务7-3：AI风险识别与处理

建议工时：

2

任务描述

AI风险识别与处理功能用于监控设备运行过程中的AI识别报警信息，提供报警查询、处理和分析功能。该页面采用响应式布局，包含多条件筛选、数据表格展示、报警详情查看、报警处理交互和分页功能，帮助用户及时发现和处理AI识别风险。

**知识点：**Vue3组合式API、响应式数据管理、API数据交互、条件渲染、表格展示、分页组件、模态框交互、日期时间处理、图像显示

**重点：**API数据交互、条件渲染、表格展示、分页组件、模态框交互

**难点：**API数据交互、条件渲染、表格展示、分页组件、模态框交互、日期时间处理

**内容：**实现AI风险识别与处理页面的完整功能，包括报警筛选条件、数据表格展示、报警详情弹框、报警处理弹框、分页组件和状态管理。

##### 2. 筛选条件组件实现

![img](https://tecs-prod-static.obs.cn-north-1.myhuaweicloud.com/33d31ac81c734ed7acfbaafafebdeeda%2Frichtext%2Fimage%2F20251203%2F468776605d754342b36b35374ccd2369.png)

筛选条件包含设备编号、报警类型、报警时间范围：

```nix
javascript
// 筛选条件数据结构
const filters = ref({
  deviceNumber: '',  // 设备编号
  alarmType: '',     // 报警类型：1-未戴安全帽，2-未穿安全衣，3-工作现场抽烟，4-夜间施工，5-工作现场明烟，6-工作现场明火
  startDate: '',     // 开始日期
  endDate: ''        // 结束日期
})

// 报警类型映射
const alarmTypes = [
  { value: 1, label: "未戴安全帽" },
  { value: 2, label: "未穿安全衣" },
  { value: 3, label: "工作现场抽烟" },
  { value: 4, label: "夜间施工" },
  { value: 5, label: "工作现场明烟" },
  { value: 6, label: "工作现场明火" }
]
```

实现要点：使用select组件提供预定义选项；

日期选择使用原生input[type="date"]；

搜索按钮触发数据重新加载；

重置按钮清空筛选条件。
